# Vim 快速查找与修改完整指南（2026 最新）

**核心结论：Vim 的查找替换功能是其最强大的特性之一，通过`/`查找、`:s`替换、正则表达式和宏录制，可以实现从简单文本修改到复杂批量处理的所有需求。掌握这些技巧后，编辑效率会远超普通编辑器。**

---

## 一、基础查找：快速定位文本

### 1. 普通模式下的基础查找

表格

|命令|功能|
|---|---|
|`/关键词`|从光标位置**向下**查找指定关键词|
|`?关键词`|从光标位置**向上**查找指定关键词|
|`n`|跳转到**下一个**匹配项（与上次查找方向相同）|
|`N`|跳转到**上一个**匹配项（与上次查找方向相反）|
|`*`|查找**光标所在单词**（向下），自动匹配整个单词|
|`#`|查找**光标所在单词**（向上），自动匹配整个单词|

**示例**：

plaintext

```
/error      # 向下查找所有"error"
?warning    # 向上查找所有"warning"
*           # 查找光标下的变量名，非常适合代码阅读
```

### 2. 查找高亮与清除

vim

```
:set hlsearch    # 开启查找高亮（推荐添加到~/.vimrc）
:set nohlsearch  # 临时关闭高亮
:nohl            # 清除当前高亮（下次查找仍会显示）
```

### 3. 行内快速查找

表格

|命令|功能|
|---|---|
|`f字符`|跳转到当前行**下一个**指定字符|
|`F字符`|跳转到当前行**上一个**指定字符|
|`t字符`|跳转到当前行**下一个**指定字符的**前面**|
|`T字符`|跳转到当前行**上一个**指定字符的**后面**|
|`;`|重复上一次行内查找|
|`,`|反向重复上一次行内查找|

**示例**：

plaintext

```
f;          # 跳转到当前行下一个分号
F(          # 跳转到当前行上一个左括号
```

## 二、基础替换：快速修改文本

Vim 的替换命令是`:s`（substitute），语法格式为：

vim

```
:[范围]s/查找内容/替换内容/[标志]
```

### 1. 最常用的替换命令

表格

|命令|功能|
|---|---|
|`:s/old/new/`|替换**当前行第一个**`old`为`new`|
|`:s/old/new/g`|替换**当前行所有**`old`为`new`|
|`:%s/old/new/g`|替换**整个文件所有**`old`为`new`（最常用）|
|`:%s/old/new/gc`|全局替换，**每次替换前确认**（安全推荐）|
|`:%s/old/new/gi`|全局替换，**忽略大小写**|

### 2. 范围替换

表格

|命令|功能|
|---|---|
|`:2,5s/old/new/g`|替换**第 2 到第 5 行**所有`old`为`new`|
|`:.,$s/old/new/g`|替换**从当前行到文件末尾**所有`old`为`new`|
|`:'<,'>s/old/new/g`|替换**可视模式选中的区域**（选中后按`:`自动填充）|
|`:/start/,/end/s/old/new/g`|替换**从匹配 start 到匹配 end 的行**|

### 3. 确认替换交互说明

使用`gc`标志时，每次匹配会提示：

plaintext

```
replace with new (y/n/a/q/l/^E/^Y)?
```

- `y`：替换当前匹配
- `n`：跳过当前匹配
- `a`：替换所有剩余匹配
- `q`：退出替换
- `l`：替换当前匹配并退出

## 三、高级查找：正则表达式与精确匹配

### 1. 常用正则表达式元字符

表格

|元字符|含义|
|---|---|
|`^`|匹配行首|
|`$`|匹配行尾|
|`.`|匹配任意单个字符|
|`*`|匹配前面的字符零次或多次|
|`\+`|匹配前面的字符一次或多次|
|`\?`|匹配前面的字符零次或一次|
|`\d`|匹配数字|
|`\w`|匹配单词字符（字母、数字、下划线）|
|`\s`|匹配空白字符（空格、tab）|
|`\<`|匹配单词开头|
|`\>`|匹配单词结尾|

### 2. 实用查找示例

vim

```
/^#.*$          # 查找所有以#开头的注释行
/^\s*$          # 查找所有空白行
/\<foo\>        # 精确匹配单词"foo"，不会匹配"foobar"
/error.*\d\+    # 查找"error"后面跟着一个或多个数字
```

### 3. Very Magic 模式（减少转义）

Vim 默认的正则表达式需要转义很多特殊字符，使用`\v`可以开启 "非常魔法" 模式，让大多数特殊字符直接生效：

vim

```
/\vfunction\s+\w+  # 匹配函数定义，无需转义+和\s
/\v\d{3}-\d{4}     # 匹配电话号码格式
```

## 四、高级替换：复杂文本处理

### 1. 引用匹配内容

使用`&`或`\0`引用整个匹配内容，`\1`、`\2`等引用分组内容：

vim

```
:%s/\<foo\>/&bar/g        # 将所有"foo"替换为"foobar"
:%s/\(\w\+\) = \1/\1/g   # 删除重复的变量赋值（如"x = x"）
:%s/^\(.*\)$/"\1"/g      # 给每一行加上双引号
```

### 2. 大小写转换

在替换内容中使用以下特殊字符进行大小写转换：

- `\U`：转换为大写，直到`\E`
- `\L`：转换为小写，直到`\E`
- `\u`：转换下一个字符为大写
- `\l`：转换下一个字符为小写

**示例**：

vim

```
:%s/\<\w\+\>/\u&/g       # 将所有单词首字母大写
:%s/\(.*\)/\U\1/g        # 将整个文件转换为大写
```

### 3. 表达式替换

使用`\=`可以在替换中执行 Vim 表达式，实现复杂的计算和逻辑：

vim

```
:%s/\d\+/\=submatch(0)+1/g  # 将所有数字加1
:%s/^/\=line('.').' '/g     # 在每一行开头添加行号
```

## 五、多文件查找与替换

### 1. 多文件查找：vimgrep

vim

```
:vimgrep /pattern/ **/*.py          # 递归搜索所有.py文件
:vimgrep /pattern/ **/*.cpp **/*.h  # 搜索多种文件类型
:copen                              # 打开快速修复窗口，显示所有匹配
:cnext                              # 跳转到下一个匹配
:cprev                              # 跳转到上一个匹配
```

### 2. 多文件替换：argdo

vim

```
:args **/*.md                       # 将所有.md文件加入参数列表
:argdo %s/old/new/ge | update       # 对所有文件执行替换并保存
```

- `e`标志：忽略无匹配的文件
- `update`：仅在文件被修改时保存

## 六、宏录制：自动化重复操作

对于复杂的重复性编辑任务，宏录制是最高效的方法：

### 1. 宏录制步骤

1. 按`q` + 字母（如`qa`）开始录制，将宏保存到寄存器`a`
2. 执行一系列编辑操作
3. 按`q`结束录制

### 2. 宏执行

vim

```
@a          # 执行寄存器a中的宏
@@          # 重复执行上一次宏
10@a        # 执行宏10次
```

### 3. 实用示例：批量添加注释

plaintext

```
qa          # 开始录制到寄存器a
^           # 跳转到行首
i# <Esc>    # 插入注释符
j           # 移动到下一行
q           # 结束录制
10@a        # 给接下来10行添加注释
```

## 七、实用配置建议

将以下配置添加到`~/.vimrc`文件中，提升查找替换体验：

vim

```
" ========== 查找配置 ==========
set hlsearch        " 开启查找高亮
set incsearch       " 增量搜索（输入时实时显示匹配）
set ignorecase      " 查找时忽略大小写
set smartcase       " 如果包含大写字母则区分大小写

" ========== 快捷键映射 ==========
nnoremap <leader>h :nohlsearch<CR>  # 按\h清除查找高亮
nnoremap <leader>s :%s//g<Left><Left>  # 按\s快速进入替换模式
```
