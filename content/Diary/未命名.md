从模型列表可以看到三组 provider：
1. opencode/ — OpenCode Zen 免费/付费模型
这些是 opencode 官方托管的模型，不需要自己买 API key，但需要注册 Zen 服务获取 API key（/connect → OpenCode Zen）。
模型	是否免费	限制
big-pickle	免费	有限期内免费，数据可能被用于改进模型
deepseek-v4-flash-free	免费	同上
hy3-free	免费	-
mimo-v2.5-free	免费	数据可能被用于改进模型
nemotron-3-ultra-free	免费	NVIDIA 提供，试用量，不要提交敏感数据
north-mini-code-free	免费	数据可能被保留用于改进模型
其他非 free 模型（如 Claude、GPT、Qwen 等）需要付费，按 token 计费，价格见 opencode.ai/zen (https://opencode.ai/zen)。
2. anthropic/ — 通过你的 DeepSeek API 路由
你配置了 baseURL: https://api.deepseek.com/anthropic，所以所有 anthropic/ 前缀的请求都发往 DeepSeek 的 Anthropic 兼容接口。
- 能用的：deepseek-v4-flash、deepseek-v4-pro[1m]（你显式配置的）
- 不可用的：其余 Claude 模型（如 claude-sonnet-4-5、claude-opus-4-8 等），DeepSeek 的接口不会返回这些
3. deepseek/ — 原生 DeepSeek API
你通过 /connect 配置了 DeepSeek credential，所以原生 deepseek/ 前缀的模型也可以直接用你的 DeepSeek API key（sk-0a38...）：
- deepseek/deepseek-chat — DeepSeek 聊天模型
- deepseek/deepseek-reasoner — 推理模型
- deepseek/deepseek-v4-flash — V4 Flash
- deepseek/deepseek-v4-pro — V4 Pro
这些走你的 DeepSeek 平台额度，按 DeepSeek 官方定价计费。
总结：opencode/ 下带 -free 的模型免费可用（需注册 Zen），其余需付费；anthropic/ 下只有你配置的两个模型能走通；deepseek/ 下走你已有的 DeepSeek API 额度。
