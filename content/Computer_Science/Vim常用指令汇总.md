## 一、基础模式与切换

Vim 有 4 种核心模式，所有操作都在特定模式下执行：

|模式|进入方式|主要用途|退出方式|
|---|---|---|---|
|**普通模式 (Normal)**|启动 Vim 默认进入；其他模式按`Esc`|移动光标、执行编辑命令|无法退出，是基础模式|
|**插入模式 (Insert)**|普通模式按`i/a/o/I/A/O`|输入文本|按`Esc`返回普通模式|
|**命令行模式 (Command)**|普通模式按`:`|执行文件操作、全局命令、设置|执行命令或按`Esc`返回|
|**可视模式 (Visual)**|普通模式按`v/V/Ctrl+v`|选择文本块进行批量操作|按`Esc`返回普通模式|

## 二、普通模式：光标移动（高效编辑的核心）

### 1. 基础移动

- `h`/`j`/`k`/`l`：左 / 下 / 上 / 右（替代方向键，手不离开主键盘）
- `gj`/`gk`：在软换行（长行自动折行）中上下移动

### 2. 单词级移动

- `w`：移动到下一个单词开头（以标点分隔）
- `W`：移动到下一个单词开头（仅以空格分隔）
- `b`：移动到上一个单词开头
- `B`：移动到上一个单词开头（仅以空格分隔）
- `e`：移动到当前单词结尾
- `E`：移动到当前单词结尾（仅以空格分隔）

### 3. 行内移动

- `0`：移动到行首（绝对行首）
- `^`：移动到行首第一个非空白字符
- `$`：移动到行尾
- `f{char}`：移动到行内下一个`{char}`字符处
- `F{char}`：移动到行内上一个`{char}`符处
- `t{char}`：移动到行内下一个`{char}`字符前
- `T{char}`：移动到行内上一个`{char}`字符后
- `;`：重复上次行内字符查找
- `,`：反向重复上次行内字符查找

### 4. 段落与屏幕移动

- `{`：移动到上一个空行（段落开头）
- `}`：移动到下一个空行（段落结尾）
- `Ctrl+f`：向下翻一屏
- `Ctrl+b`：向上翻一屏
- `Ctrl+d`：向下翻半屏
- `Ctrl+u`：向上翻半屏
- `zz`：将当前行置于屏幕中央
- `zt`：将当前行置于屏幕顶部
- `zb`：将当前行置于屏幕底部

### 5. 文件级移动

- `gg`：移动到文件第一行
- `G`：移动到文件最后一行
- `{n}G`：移动到第`n`行（例如`100G`跳转到第 100 行）
- `:{n}`：命令行模式下跳转到第`n`行
- `Ctrl+o`：跳转到上一个光标位置
- `Ctrl+i`：跳转到下一个光标位置

## 三、普通模式：编辑操作

### 1. 插入文本（进入插入模式）

- `i`：在光标**前**插入
- `I`：在行首第一个非空白字符前插入
- `a`：在光标**后**插入
- `A`：在行尾插入
- `o`：在当前行**下方**新建一行并插入
- `O`：在当前行**上方**新建一行并插入
- `s`：删除光标处字符并插入
- `S`：删除整行并插入
- `C`：删除从光标到行尾的内容并插入

### 2. 删除操作

- `x`：删除光标处单个字符
- `X`：删除光标前单个字符
- `d{动作}`：删除指定范围的内容（操作符 + 动作）
    
    - `dw`：删除从光标到下一个单词开头
    - `daw`：删除整个单词（包括周围空格）
    - `diw`：删除整个单词（不包括周围空格）
    - `dd`：删除整行
    - `d$`：删除从光标到行尾
    - `d^`：删除从光标到行首非空白字符
    - `dgg`：删除从光标到文件开头
    - `dG`：删除从光标到文件结尾
    
- `{n}dd`：删除从当前行开始的`n`行

### 3. 复制与粘贴

- `y{动作}`：复制指定范围的内容
    
    - `yw`：复制一个单词
    - `yy`：复制整行
    - `y$`：复制从光标到行尾
    
- `{n}yy`：复制从当前行开始的`n`行
- `p`：在光标**后**粘贴（如果是整行则粘贴到下一行）
- `P`：在光标**前**粘贴（如果是整行则粘贴到上一行）

### 4. 撤销与重做

- `u`：撤销上一次操作
- `Ctrl+r`：重做上一次撤销的操作
- `U`：撤销对当前行的所有修改（仅当光标未离开该行时有效）

### 5. 修改操作

- `r{char}`：将光标处字符替换为`{char}`
- `R`：进入替换模式，输入的字符会覆盖原有字符
- `c{动作}`：删除指定范围内容并进入插入模式
    
    - `cw`：修改一个单词
    - `cc`：修改整行
    - `c$`：修改从光标到行尾
    
- `~`：切换光标处字符的大小写

## 四、可视模式：文本选择与批量操作

### 1. 进入可视模式

- `v`：字符可视模式（按字符选择）
- `V`：行可视模式（按行选择）
- `Ctrl+v`：块可视模式（按矩形块选择，非常强大）

### 2. 选择操作

- 移动光标扩展选择范围
- `o`：切换选择块的活动端点
- `aw`：选择整个单词
- `ab`：选择一个括号块（包括括号）
- `ib`：选择一个括号块（不包括括号）
- `a"`：选择一个双引号块（包括引号）
- `i"`：选择一个双引号块（不包括引号）

### 3. 批量操作

选择文本后可执行以下命令：

- `d`：删除选中内容
- `y`：复制选中内容
- `c`：删除选中内容并进入插入模式
- `>`：向右缩进
- `<`：向左缩进
- `=`：自动缩进
- `gU`：转换为大写
- `gu`：转换为小写

### 4. 块可视模式高级用法

1. 按`Ctrl+v`进入块模式
2. 选择要操作的矩形区域
3. 按`I`进入插入模式，输入内容
4. 按`Esc`，输入的内容会出现在所有选中行的相同位置

## 五、命令行模式：文件与全局操作

### 1. 文件操作

- `:w`：保存文件
- `:w {filename}`：另存为`{filename}`
- `:q`：退出 Vim（未修改时）
- `:q!`：强制退出不保存
- `:wq`/`:x`：保存并退出
- `:e {filename}`：打开另一个文件
- `:e!`：重新加载当前文件（放弃所有修改）
- `:saveas {filename}`：另存为并切换到新文件

### 2. 搜索与替换

#### 基础搜索

- `/{pattern}`：向下搜索`{pattern}`
- `?{pattern}`：向上搜索`{pattern}`
- `n`：跳转到下一个匹配项
- `N`：跳转到上一个匹配项
- `*`：向下搜索光标处的单词
- `#`：向上搜索光标处的单词

#### 全局替换

语法：`:[范围]s/旧内容/新内容/[标志]`

- 范围：
    
    - 不写：仅当前行
    - `%`：整个文件
    - `1,10`：第 1 行到第 10 行
    - `.,$`：当前行到文件结尾
    
- 标志：
    
    - `g`：全局替换（一行内所有匹配）
    - `c`：替换前确认
    - `i`：忽略大小写
    
- 示例：
    
    - `:%s/foo/bar/g`：将文件中所有`foo`替换为`bar`
    - `:%s/foo/bar/gc`：全局替换并逐个确认
    - `:1,10s/^/#/g`：在第 1-10 行开头添加`#`注释
    

### 3. 常用设置

- `:set number`/`:set nu`：显示行号
- `:set nonumber`/`:set nonu`：隐藏行号
- `:set relativenumber`/`:set rnu`：显示相对行号
- `:set autoindent`/`:set ai`：自动缩进
- `:set expandtab`/`:set et`：将 Tab 转换为空格
- `:set tabstop=4`/`:set ts=4`：设置 Tab 宽度为 4 个空格
- `:set shiftwidth=4`/`:set sw=4`：设置缩进宽度为 4 个空格
- `:set hlsearch`/`:set hls`：高亮搜索结果
- `:set nohlsearch`/`:set nohls`：取消搜索结果高亮

### 4. 其他常用命令

- `:!{command}`：执行外部 shell 命令
- `:r {filename}`：将`{filename}`的内容插入到当前行下方
- `:r !{command}`：将外部命令的输出插入到当前行下方
- `:help {topic}`：查看帮助文档

## 六、多窗口与多标签页

### 1. 窗口分割

- `:sp {filename}`：水平分割窗口，打开`{filename}`
- `:vsp {filename}`：垂直分割窗口，打开`{filename}`
- `Ctrl+w s`：水平分割当前窗口
- `Ctrl+w v`：垂直分割当前窗口

### 2. 窗口操作

- `Ctrl+w h/j/k/l`：切换到左 / 下 / 上 / 右窗口
- `Ctrl+w w`：循环切换窗口
- `Ctrl+w q`：关闭当前窗口
- `Ctrl+w o`：关闭其他所有窗口，只保留当前窗口
- `Ctrl+w =`：使所有窗口大小相等
- `Ctrl+w +`：增加当前窗口高度
- `Ctrl+w -`：减少当前窗口高度
- `Ctrl+w >`：增加当前窗口宽度
- `Ctrl+w <`：减少当前窗口宽度

### 3. 标签页操作

- `:tabnew {filename}`：新建标签页，打开`{filename}`
- `gt`：切换到下一个标签页
- `gT`：切换到上一个标签页
- `{n}gt`：切换到第`n`个标签页
- `:tabclose`：关闭当前标签页
- `:tabonly`：关闭其他所有标签页

## 七、高级功能

### 1. 宏录制（自动化重复操作）

- `q{字母}`：开始录制宏到寄存器`{字母}`
- 执行需要重复的操作
- `q`：结束录制
- `@{字母}`：执行录制好的宏
- `@@`：重复执行上一个宏
- `{n}@{字母}`：执行宏`n`次

### 2. 寄存器操作

Vim 有多个寄存器用于保存文本，默认使用无名寄存器`""`

- `"ayy`：复制当前行到寄存器`a`
- `"ap`：粘贴寄存器`a`中的内容
- `:reg`：查看所有寄存器内容
- `"+y`：复制到系统剪贴板（需要 Vim 支持剪贴板）
- `"+p`：从系统剪贴板粘贴

### 3. 标记

- `m{字母}`：在当前位置设置标记`{字母}`
- ```{字母}`：跳转到标记`{字母}` 的精确位置
- `'{字母}`：跳转到标记`{字母}`所在行的行首
- `:marks`：查看所有标记

## 八、新手必记救命指令

1. 无论在什么模式，按`Esc`回到普通模式
2. 不知道怎么退出：按`Esc`，然后输入`:q!`强制退出不保存
3. 想保存退出：按`Esc`，然后输入`:wq`
4. 操作错了：按`u`撤销
5. 想查看帮助：输入`:help`
