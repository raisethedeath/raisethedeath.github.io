**习题 12.58** 为使过程 $\pi + p \to K + \Sigma$ 发生，计算 $\pi$ 介子的临界（最小的）动量。质子 $p$ 初始时处于静止状态。利用 $m_{\pi}c^2 = 150, m_Kc^2 = 500, m_{\Sigma}c^2 = 900, m_{\Sigma}c^2 = 1200$（所有的单位均为 $\text{MeV}$）。[提示：为了求临界条件，以碰撞的动量中心为参考系（习题 12.30）。答案：1133 $\text{MeV}/c$]
## Solution
这是一道非常经典的相对论运动学问题（常出现在格里菲斯的《电动力学导论》中）。

在开始解答前，我们需要先**纠正题干中的一个笔误**：
题目中给出了两次 $m_{\Sigma}c^2$ 的数值（$900$ 和 $1200$），且漏掉了质子 $p$ 的静止能量。根据前后文及粒子物理的常识，这里显然有一个是质子的静止能量。为了能算出给定的答案 $1133\text{ MeV}/c$，正确的静止能量参数应为：
*   $\pi$介子：$m_{\pi}c^2 = 150 \text{ MeV}$
*   质子$p$：$m_pc^2 = 900 \text{ MeV}$
*   $K$介子：$m_Kc^2 = 500 \text{ MeV}$
*   $\Sigma$超子：$m_{\Sigma}c^2 = 1200 \text{ MeV}$

下面是详细的推导与解答过程：

### 1. 物理思路分析
在粒子物理反应中，寻找“临界（最小的）动量”意味着我们要找到刚好能产生目标粒子的最低能量（阈值能量）。
题目的提示建议使用**动量中心系（质心系，CM frame）**，因为在质心系中，系统的总动量恒为零。
在阈值条件下，碰撞刚刚好能生成 $K$ 和 $\Sigma$ 粒子，而没有多余的能量转化为它们的动能。因此，**在质心系中，生成的 $K$ 和 $\Sigma$ 粒子必定是静止的**。

利用相对论中极其重要的**四维动量平方守恒（洛伦兹不变量）**，我们可以将“实验室参考系”和“质心参考系”联系起来。
不变量公式为：$(P_{\text{总}} c)^2 = E_{\text{总}}^2 - (p_{\text{总}}c)^2 = \text{不变常数}$。

### 2. 在“质心参考系”中计算不变量
在临界阈值条件下的质心系中，生成的 $K$ 粒子和 $\Sigma$ 粒子处于静止状态（总动量 $p_{\text{CM}} = 0$）。
此时系统的总能量 $E_{\text{CM}}$ 等于生成物的静止能量之和：
$$E_{\text{CM}} = m_K c^2 + m_{\Sigma} c^2 = 500 \text{ MeV} + 1200 \text{ MeV} = 1700 \text{ MeV}$$

所以，系统的洛伦兹不变量（不变质量的平方乘 $c^4$）为：
$$I = E_{\text{CM}}^2 - (p_{\text{CM}}c)^2 = (1700)^2 - 0 = 2890000 \text{ MeV}^2$$

### 3. 在“实验室参考系”中计算不变量并建立方程
在实验室系中，质子 $p$ 最初是静止的，$\pi$ 介子具有入射动量 $p_{\pi}$ 和总能量 $E_{\pi}$。
*   质子的能量：$E_p = m_p c^2 = 900 \text{ MeV}$，动量 $p_p = 0$
*   $\pi$ 介子的能量与动量的关系：$E_{\pi}^2 - (p_{\pi}c)^2 = (m_{\pi} c^2)^2$
*   碰撞前的总能量：$E_{\text{lab}} = E_{\pi} + m_p c^2$
*   碰撞前的总动量：$p_{\text{lab}} = p_{\pi}$

计算实验室系下的不变量：
$$I = E_{\text{lab}}^2 - (p_{\text{lab}}c)^2$$
$$I = (E_{\pi} + m_p c^2)^2 - (p_{\pi}c)^2$$
展开平方项：
$$I = E_{\pi}^2 + (m_p c^2)^2 + 2E_{\pi}(m_p c^2) - (p_{\pi}c)^2$$
将 $E_{\pi}^2 - (p_{\pi}c)^2$ 替换为 $\pi$ 介子的静能平方 $(m_{\pi} c^2)^2$：
$$I = (m_{\pi} c^2)^2 + (m_p c^2)^2 + 2E_{\pi}(m_p c^2)$$

### 4. 联立求解 $\pi$ 介子的临界能量 $E_{\pi}$
因为不变量 $I$ 在任何惯性系下都相等，所以我们将质心系和实验室系的结果等号相连：
$$(m_{\pi} c^2)^2 + (m_p c^2)^2 + 2E_{\pi}(m_p c^2) = E_{\text{CM}}^2$$
代入已知数值：
$$150^2 + 900^2 + 2 \cdot E_{\pi} \cdot 900 = 1700^2$$
$$22500 + 810000 + 1800 \cdot E_{\pi} = 2890000$$
$$832500 + 1800 \cdot E_{\pi} = 2890000$$
$$1800 \cdot E_{\pi} = 2057500$$
$$E_{\pi} = \frac{2057500}{1800} \approx 1143.06 \text{ MeV}$$
（这就是发生反应所需的入射 $\pi$ 介子的总能量）

### 5. 计算临界动量 $p_{\pi}$
利用能量-动量关系式 $E_{\pi}^2 = (p_{\pi}c)^2 + (m_{\pi} c^2)^2$，解出 $p_{\pi}c$：
$$(p_{\pi}c)^2 = E_{\pi}^2 - (m_{\pi} c^2)^2$$
$$(p_{\pi}c)^2 = \left( \frac{205750}{180} \right)^2 - 150^2$$
$$(p_{\pi}c)^2 \approx 1306576 - 22500 = 1284076 \text{ MeV}^2$$
$$p_{\pi}c = \sqrt{1284076} \approx 1133.17 \text{ MeV}$$

由于通常动量的单位写为 $\text{MeV}/c$，所以：
$$p_{\pi} \approx 1133 \text{ MeV}/c$$

**答案与结论：**
发生该反应的 $\pi$ 介子临界（最小的）动量为 **$1133 \text{ MeV}/c$**。推导结果与参考答案完全一致。

## Solution 2
**完全可以！而且你提出的这个思路非常深刻。**

利用“四维动量不变量”求解是最讨巧、最程式化的代数方法；但**你提出的这种“在质心系中计算，再通过洛伦兹变换逆推回实验室系”的思路，物理图像最为清晰**，它能让你真正看到两个参考系之间究竟发生了怎样的物理过程。

下面我将用你的思路，一步步推导并证明它与之前的答案完美吻合（而且在推导过程中，我们会发现一个极其优美的代数化简）。

---

### 第一步：在动量中心系（COM）中分析碰撞前的粒子
在阈值条件下，碰撞后生成的 $K$ 介子和 $\Sigma$ 超子在 COM 系中是**绝对静止**的。
因此，COM 系的总能量 $E_{\text{CM}}$ 就是生成物的静止能量之和：
$$E_{\text{CM}} = m_K c^2 + m_{\Sigma} c^2 = 500 + 1200 = 1700 \text{ MeV}$$

在碰撞前，$\pi$ 介子和质子 $p$ 在 COM 系中相向而行，总动量为零。设它们的动量大小均为 $p'$，能量分别为 $E_{\pi}'$ 和 $E_p'$。
满足以下能量守恒方程：
$$E_{\pi}' + E_p' = E_{\text{CM}} = 1700 \text{ MeV}$$
其中，$E_{\pi}' = \sqrt{(p'c)^2 + (m_{\pi} c^2)^2}$，$E_p' = \sqrt{(p'c)^2 + (m_p c^2)^2}$。

这是一个标准的相对论运动学方程，解这个方程求 $E_p'$ 和 $E_{\pi}'$ 有一个通用公式（将根号移项平方即可得到）：
$$E_p' = \frac{E_{\text{CM}}^2 + (m_p c^2)^2 - (m_{\pi} c^2)^2}{2E_{\text{CM}}}$$
$$E_{\pi}' = \frac{E_{\text{CM}}^2 + (m_{\pi} c^2)^2 - (m_p c^2)^2}{2E_{\text{CM}}}$$

代入数值：
$$E_p' = \frac{1700^2 + 900^2 - 150^2}{2 \times 1700} = \frac{2890000 + 810000 - 22500}{3400} = \frac{3677500}{3400} \approx 1081.62 \text{ MeV}$$
计算此时 COM 系中的动量 $p'$：
$$p'c = \sqrt{E_p'^2 - (m_p c^2)^2} = \sqrt{1081.62^2 - 900^2} \approx 599.91 \text{ MeV}$$

---

### 第二步：寻找 COM 系与实验室系之间的洛伦兹变换因子 $\gamma$ 和 $\beta$
这是最巧妙的一步！
在 COM 系中，质子正在以动量 $p'$ 和能量 $E_p'$ 运动。
**而在实验室系中，质子是静止的！**
这意味着什么？这意味着 **COM 系相对于实验室系的运动速度，刚好就等于质子在 COM 系中的运动速度！**

因此，连接这两个参考系的洛伦兹因子 $\gamma$ 和相对速度 $\beta$ ，直接可以由质子在 COM 系中的状态写出：
$$\gamma = \frac{E_p'}{m_p c^2}$$
$$\beta = \frac{p'c}{E_p'}$$

*(代入数值的话，$\gamma = 1081.62 / 900 \approx 1.2018$，$\beta \approx 0.5546$)*

---

### 第三步：利用洛伦兹变换，把 $\pi$ 介子“变”回实验室系
在 COM 系中，$\pi$ 介子的动量为 $p'$，方向与质子相反。我们要把它变回质子静止的实验室系，相当于沿着 $\pi$ 介子运动的方向进行一次速度为 $\beta$ 的洛伦兹逆变换（Boost）。

根据动量的洛伦兹变换公式，实验室系中 $\pi$ 介子的动量 $p_{\text{lab}}$ 为：
$$p_{\text{lab}} c = \gamma (p' c + \beta E_{\pi}')$$

现在，我们把第二步求出的 $\gamma$ 和 $\beta$ 代入这个式子。**此时会出现一个无比优雅的化简：**
$$p_{\text{lab}} c = \frac{E_p'}{m_p c^2} \left( p'c + \frac{p'c}{E_p'} E_{\pi}' \right)$$
将外面的 $E_p'$ 乘进去：
$$p_{\text{lab}} c = \frac{1}{m_p c^2} \left( p'c \cdot E_p' + p'c \cdot E_{\pi}' \right)$$
提取公因式 $p'c$：
$$p_{\text{lab}} c = \frac{p'c}{m_p c^2} (E_p' + E_{\pi}')$$

别忘了第一步中我们说过，$E_p' + E_{\pi}'$ 正是 COM 系的总能量 $E_{\text{CM}}$！
所以，最终的极其精简的表达式为：
$$\mathbf{p_{\text{lab}} c = p' c \cdot \frac{E_{\text{CM}}}{m_p c^2}}$$

### 结论验算
我们将前面的数值代入这个最终公式：
*   $p'c \approx 599.914 \text{ MeV}$
*   $E_{\text{CM}} = 1700 \text{ MeV}$
*   $m_p c^2 = 900 \text{ MeV}$

$$p_{\text{lab}} c = 599.914 \times \frac{1700}{900} = 599.914 \times 1.88889 \approx \mathbf{1133.17 \text{ MeV}}$$

也就是：
**$p_{\text{lab}} \approx 1133 \text{ MeV}/c$**

**总结：**
你的思路不仅完全正确，而且在物理上揭示了一个极其深刻的联系：**实验室系入射粒子的动量，实质上等于质心系动量乘以一个无量纲的放大因子 ($E_{\text{CM}} / m_{\text{靶} } c^2$)**。这正是高等粒子物理学中进行参考系变换时最喜欢使用的直观图像！
