### 第一题：一维周期势的傅里叶分量与久期行列式

**题目：** 考虑一维周期势: $V(x) = V_0 \cos\left( \frac{2\pi x}{a} \right)$
(1) 请写出该势场的傅里叶分量 $V(G)$。
(2) 若只保留 $G = 0, \pm g$ 三个平面波，请推导能量满足的久期行列式。

**解答：**

**(1) 求傅里叶分量 $V(G)$**
一维晶格的倒格矢为 $G = n \frac{2\pi}{a}$（$n$ 为整数）。令基矢 $g = \frac{2\pi}{a}$，则 $G = ng$。
利用欧拉公式将势能展开：
$$V(x) = V_0 \cos\left( g x \right) = \frac{V_0}{2} e^{i g x} + \frac{V_0}{2} e^{-i g x}$$
根据周期势的傅里叶展开定义 $V(x) = \sum_{G} V(G) e^{i G x}$，对比系数可知：
只有当 $G = g$ 和 $G = -g$ 时，傅里叶分量不为零：
$$V(g) = \frac{V_0}{2}, \quad V(-g) = \frac{V_0}{2}$$
对于其他所有的 $G$（包括 $G=0$），均有 $V(G) = 0$。

**(2) 推导久期行列式**
根据近自由电子近似的中心方程：
$$(E_{k-G}^0 - E) C_{k-G} + \sum_{G'} V(G'-G) C_{k-G'} = 0$$
其中自由电子能量 $E_q^0 = \frac{\hbar^2 q^2}{2m}$。
题目要求只保留 $G = 0, g, -g$ 三个平面波，即波函数近似为 $\psi_k(x) = C_k e^{ikx} + C_{k-g} e^{i(k-g)x} + C_{k+g} e^{i(k+g)x}$。
我们分别取方程的指标为 $G = g, 0, -g$，并只保留相应的三个系数：

*   当 $G = g$ 时，有 $(E_{k-g}^0 - E) C_{k-g} + V(-g) C_k + V(-2g) C_{k+g} = 0$。因为 $V(-2g)=0$，所以：
    $$(E_{k-g}^0 - E) C_{k-g} + \frac{V_0}{2} C_k = 0$$
*   当 $G = 0$ 时，有 $(E_{k}^0 - E) C_k + V(g) C_{k-g} + V(-g) C_{k+g} = 0$，所以：
    $$\frac{V_0}{2} C_{k-g} + (E_{k}^0 - E) C_k + \frac{V_0}{2} C_{k+g} = 0$$
*   当 $G = -g$ 时，有 $(E_{k+g}^0 - E) C_{k+g} + V(2g) C_{k-g} + V(g) C_k = 0$。因为 $V(2g)=0$，所以：
    $$\frac{V_0}{2} C_k + (E_{k+g}^0 - E) C_{k+g} = 0$$

要使方程组有非零解，系数行列式必须为零，写成矩阵形式（按 $C_{k-g}, C_k, C_{k+g}$ 的顺序）：
$$
\begin{vmatrix}
E_{k-g}^0 - E & \frac{V_0}{2} & 0 \\
\frac{V_0}{2} & E_k^0 - E & \frac{V_0}{2} \\
0 & \frac{V_0}{2} & E_{k+g}^0 - E
\end{vmatrix} = 0
$$
这就是所求的能量 $E$ 满足的久期行列式。

### 4.1 布洛赫定理与波矢求解

**题目：** 布洛赫定理要求 $\psi_k(x+a) = e^{ika} \psi_k(x)$，求给定波函数的波矢 $k$。

**解答：**
根据布洛赫定理：$\psi_k(x+a) = e^{ika} \psi_k(x)$。
**(a)** $\psi_k(x) = \sin\left( \frac{\pi x}{a} \right)$
将 $x \to x+a$ 代入：
$$\psi_k(x+a) = \sin\left( \frac{\pi (x+a)}{a} \right) = \sin\left( \frac{\pi x}{a} + \pi \right) = -\sin\left( \frac{\pi x}{a} \right) = -\psi_k(x)$$
即 $e^{ika} = -1 = e^{i\pi}$。
解得波矢 $k = \frac{\pi}{a} + \frac{2n\pi}{a}$。若将其限制在第一布里渊区内（$n=0$ 或 $n=-1$），则 **$k = \frac{\pi}{a}$** 或 **$k = -\frac{\pi}{a}$**（它们在倒空间是等价的）。

**(b)** $\psi_k(x) = \mathrm{i}\cos\left( \frac{3\pi x}{a} \right)$
将 $x \to x+a$ 代入：
$$\psi_k(x+a) = \mathrm{i}\cos\left( \frac{3\pi (x+a)}{a} \right) = \mathrm{i}\cos\left( \frac{3\pi x}{a} + 3\pi \right) = -\mathrm{i}\cos\left( \frac{3\pi x}{a} \right) = -\psi_k(x)$$
即 $e^{ika} = -1$。
解得波矢 $k = \frac{3\pi}{a}$。利用倒格矢平移将其折叠回第一布里渊区 $k' = \frac{3\pi}{a} - \frac{2\pi}{a} = \frac{\pi}{a}$。
因此第一布里渊区内的波矢为 **$k = \frac{\pi}{a}$**。

**(c)** $\psi_k(x) = \sum_{l=-\infty}^{+\infty} f(x-la)$
将 $x \to x+a$ 代入：
$$\psi_k(x+a) = \sum_{l=-\infty}^{+\infty} f(x+a-la) = \sum_{l=-\infty}^{+\infty} f(x - (l-1)a)$$
令 $l' = l-1$，当 $l$ 取遍全体整数时，$l'$ 也取遍全体整数，故：
$$\psi_k(x+a) = \sum_{l'=-\infty}^{+\infty} f(x - l'a) = \psi_k(x)$$
即 $e^{ika} = 1 = e^{i0}$。
解得第一布里渊区内的波矢为 **$k = 0$**。

### 4.5 二维正方晶格的周期势

**题目：** $V(\boldsymbol{r}) = -4U\cos\frac{2\pi x}{a}\cos\frac{2\pi y}{a}$，求：
(a) 傅里叶系数 $V(\boldsymbol{K}_h)$；
(b) 近自由电子近似下产生布拉格反射的布里渊区界线及相应能隙。

**解答：**
**(a) 傅里叶系数：**
二维正方晶格的倒格矢为 $\boldsymbol{K}_{h_1, h_2} = h_1 \frac{2\pi}{a} \hat{i} + h_2 \frac{2\pi}{a} \hat{j}$。
用欧拉公式展开电势：
$$V(x,y) = -4U \left( \frac{e^{i \frac{2\pi x}{a}} + e^{-i \frac{2\pi x}{a}}}{2} \right) \left( \frac{e^{i \frac{2\pi y}{a}} + e^{-i \frac{2\pi y}{a}}}{2} \right)$$
$$= -U \left[ e^{i\frac{2\pi}{a}(x+y)} + e^{i\frac{2\pi}{a}(x-y)} + e^{i\frac{2\pi}{a}(-x+y)} + e^{-i\frac{2\pi}{a}(x+y)} \right]$$
对比傅里叶展开式 $V(\boldsymbol{r}) = \sum_{\boldsymbol{K}} V(\boldsymbol{K}) e^{i \boldsymbol{K} \cdot \boldsymbol{r}}$，非零的傅里叶系数共有四个，对应于 $(h_1, h_2) = (1,1), (1,-1), (-1,1), (-1,-1)$：
$$V\left(\pm\frac{2\pi}{a}, \pm\frac{2\pi}{a}\right) = -U$$
其他的 $V(\boldsymbol{K}_h) = 0$。

**(b) 布拉格反射界线与能隙：**
布拉格反射发生在倒空间满足 $\boldsymbol{k} \cdot \boldsymbol{K} = \frac{1}{2}|\boldsymbol{K}|^2$ 的平面（在二维中为直线）上，且要求 $V(\boldsymbol{K}) \neq 0$。
根据(a)，有效的倒格矢为 $\boldsymbol{K} = (\pm\frac{2\pi}{a}, \pm\frac{2\pi}{a})$。
此时 $|\boldsymbol{K}|^2 = (\pm\frac{2\pi}{a})^2 + (\pm\frac{2\pi}{a})^2 = \frac{8\pi^2}{a^2}$。
代入布拉格衍射条件方程：
$$k_x \left(\pm\frac{2\pi}{a}\right) + k_y \left(\pm\frac{2\pi}{a}\right) = \frac{1}{2} \cdot \frac{8\pi^2}{a^2}$$
化简得到：
$$\pm k_x \pm k_y = \frac{2\pi}{a}$$
这是四条直线，构成了在 $k_x$-$k_y$ 平面上**第二布里渊区**的边界（一个倾斜45度的正方形）。在这四条线上有布拉格反射。
在这些边界上，能量简并被打破，产生的能隙大小为：
$$E_{gap} = 2 |V(\boldsymbol{K})| = 2|-U| = 2U$$

### 4.6 证明布里渊区界面电子垂直速度为 0

**题目：** 已知布里渊区边界附近能量公式 $E_{\pm}(\boldsymbol{k})$，证明在布里渊区界面上，垂直于界面的电子速度分量为0。

**解答：**
电子群速度由公式决定：$\boldsymbol{v} = \frac{1}{\hbar} \nabla_{\boldsymbol{k}} E(\boldsymbol{k})$。
给定的能量表达式为：
$$E_{\pm}(\boldsymbol{k}) = \frac{1}{2} \left[ E^0(\boldsymbol{k}) + E^0(\boldsymbol{k}+\boldsymbol{K}_h) \right] \pm \frac{1}{2} \sqrt{\left[ E^0(\boldsymbol{k}) - E^0(\boldsymbol{k}+\boldsymbol{K}_h) \right]^2 + 4 |V(\boldsymbol{K}_h)|^2}$$
我们对 $\boldsymbol{k}$ 求梯度 $\nabla_{\boldsymbol{k}}$：
$$ \nabla_{\boldsymbol{k}} E_{\pm} = \frac{1}{2} \left[ \nabla E^0(\boldsymbol{k}) + \nabla E^0(\boldsymbol{k}+\boldsymbol{K}_h) \right] \pm \frac{2 \left[ E^0(\boldsymbol{k}) - E^0(\boldsymbol{k}+\boldsymbol{K}_h) \right] \left[ \nabla E^0(\boldsymbol{k}) - \nabla E^0(\boldsymbol{k}+\boldsymbol{K}_h) \right]}{4 \sqrt{\dots}} $$
在布里渊区界面上，满足劳厄衍射条件，即原自由电子能量发生简并：
$$E^0(\boldsymbol{k}) = E^0(\boldsymbol{k}+\boldsymbol{K}_h)$$
因此，根号前面那一项分子中的 $E^0(\boldsymbol{k}) - E^0(\boldsymbol{k}+\boldsymbol{K}_h) = 0$，上述梯度的后半部分完全消失。
我们在边界上的梯度简化为：
$$ \nabla_{\boldsymbol{k}} E_{\pm} = \frac{1}{2} \left[ \nabla E^0(\boldsymbol{k}) + \nabla E^0(\boldsymbol{k}+\boldsymbol{K}_h) \right] $$
因为自由电子能量 $E^0(\boldsymbol{k}) = \frac{\hbar^2 k^2}{2m}$，故 $\nabla_{\boldsymbol{k}} E^0(\boldsymbol{k}) = \frac{\hbar^2}{m} \boldsymbol{k}$。代入得：
$$ \nabla_{\boldsymbol{k}} E_{\pm} = \frac{1}{2} \frac{\hbar^2}{m} \left( \boldsymbol{k} + \boldsymbol{k} + \boldsymbol{K}_h \right) = \frac{\hbar^2}{m} \left( \boldsymbol{k} + \frac{1}{2}\boldsymbol{K}_h \right) $$

布里渊区边界是由倒格矢 $\boldsymbol{K}_h$ 的垂直平分面定义的，因此**垂直于布里渊区界面的方向就是 $\boldsymbol{K}_h$ 的方向**。
我们求速度在此方向上的投影分量：
$$ v_{\perp} = \boldsymbol{v} \cdot \frac{\boldsymbol{K}_h}{|\boldsymbol{K}_h|} = \frac{1}{\hbar} \left[ \frac{\hbar^2}{m} \left( \boldsymbol{k} + \frac{1}{2}\boldsymbol{K}_h \right) \right] \cdot \frac{\boldsymbol{K}_h}{K_h} $$
由于界面本身满足 $E^0(\boldsymbol{k}) = E^0(\boldsymbol{k}+\boldsymbol{K}_h)$，即 $\boldsymbol{k}^2 = (\boldsymbol{k}+\boldsymbol{K}_h)^2$，展开后得出 $\boldsymbol{k} \cdot \boldsymbol{K}_h = -\frac{1}{2} K_h^2$（即布拉格衍射条件）。
代入上式计算点积：
$$ \left( \boldsymbol{k} + \frac{1}{2}\boldsymbol{K}_h \right) \cdot \boldsymbol{K}_h = \boldsymbol{k} \cdot \boldsymbol{K}_h + \frac{1}{2}K_h^2 = -\frac{1}{2}K_h^2 + \frac{1}{2}K_h^2 = 0 $$
结论得出 $v_{\perp} = 0$，证明完毕。

### 4.7 二维长方晶格的近自由电子近似

**题目：** $V(\boldsymbol{r}) = V_0 + A\cos\frac{4\pi x}{a} + B\cos\frac{2\pi y}{a}$，求电子状态 $\boldsymbol{k} = \left( \frac{2\pi}{a}, k_y \right)$ 的能量及相应波函数。

**解答：**
首先将势能进行傅里叶展开：
$$ V(\boldsymbol{r}) = V_0 + \frac{A}{2} e^{i \frac{4\pi}{a} x} + \frac{A}{2} e^{-i \frac{4\pi}{a} x} + \frac{B}{2} e^{i \frac{2\pi}{a} y} + \frac{B}{2} e^{-i \frac{2\pi}{a} y} $$
我们考察给定的波矢 $\boldsymbol{k} = \left( \frac{2\pi}{a}, k_y \right)$。
尝试寻找一个倒格矢 $\boldsymbol{K}$ 使其在布拉格边界上，即 $E^0_{\boldsymbol{k}} = E^0_{\boldsymbol{k}-\boldsymbol{K}}$。
考虑倒格矢 $\boldsymbol{K} = \left( \frac{4\pi}{a}, 0 \right)$（由于有 $A$ 这一项，该倒格矢对应的傅里叶系数不为 0，且 $V(\boldsymbol{K}) = \frac{A}{2}$）。
此时，$\boldsymbol{k}' = \boldsymbol{k} - \boldsymbol{K} = \left( \frac{2\pi}{a} - \frac{4\pi}{a}, k_y \right) = \left( -\frac{2\pi}{a}, k_y \right)$。
显然：
$$ E^0_{\boldsymbol{k}} = \frac{\hbar^2}{2m} \left[ \left(\frac{2\pi}{a}\right)^2 + k_y^2 \right] = \frac{\hbar^2}{2m} \left[ \left(-\frac{2\pi}{a}\right)^2 + k_y^2 \right] = E^0_{\boldsymbol{k}-\boldsymbol{K}} $$
即状态 $|\boldsymbol{k}\rangle$ 和 $|\boldsymbol{k}-\boldsymbol{K}\rangle$ 发生二重简并。对于一般情况，势能中的 $B$ 项不引起进一步简并。需要利用微扰论中的简并条件来求解能量。

建立 $2 \times 2$ 久期行列式（以 $|\boldsymbol{k}\rangle$ 和 $|\boldsymbol{k}'\rangle$ 为基底）：
$$
\begin{vmatrix}
E^0_{\boldsymbol{k}} + V_0 - E & V(\boldsymbol{K}) \\
V(-\boldsymbol{K}) & E^0_{\boldsymbol{k}'} + V_0 - E
\end{vmatrix} = 0
$$
将已知量代入（其中 $E^0_{\boldsymbol{k}} = E^0_{\boldsymbol{k}'}$， $V(\boldsymbol{K}) = V(-\boldsymbol{K}) = \frac{A}{2}$）：
$$
\begin{vmatrix}
E^0_{\boldsymbol{k}} + V_0 - E & \frac{A}{2} \\
\frac{A}{2} & E^0_{\boldsymbol{k}} + V_0 - E
\end{vmatrix} = 0
$$
解此行列式得到 $(E^0_{\boldsymbol{k}} + V_0 - E)^2 = \left(\frac{A}{2}\right)^2$，因此修正后的能量为：
$$ E_{\pm} = E^0_{\boldsymbol{k}} + V_0 \pm \frac{A}{2} = \frac{\hbar^2}{2m} \left( \frac{4\pi^2}{a^2} + k_y^2 \right) + V_0 \pm \frac{A}{2} $$

现在求对应的波函数 $\psi_{\pm} = C_1 e^{i\boldsymbol{k}\cdot\boldsymbol{r}} + C_2 e^{i\boldsymbol{k}'\cdot\boldsymbol{r}}$：
1. **对于 $E_+$ (即 $E = E^0_{\boldsymbol{k}} + V_0 + \frac{A}{2}$):**
   代入矩阵方程有 $-\frac{A}{2} C_1 + \frac{A}{2} C_2 = 0 \Rightarrow C_1 = C_2$。
   取归一化常数使其简单（如不考虑晶体体积系数，仅提取函数关系）：
   $$ \psi_+ \propto e^{i (\frac{2\pi}{a}x + k_y y)} + e^{i (-\frac{2\pi}{a}x + k_y y)} = e^{i k_y y} \left( e^{i\frac{2\pi x}{a}} + e^{-i\frac{2\pi x}{a}} \right) = 2 \cos\left(\frac{2\pi x}{a}\right) e^{i k_y y} $$

2. **对于 $E_-$ (即 $E = E^0_{\boldsymbol{k}} + V_0 - \frac{A}{2}$):**
   代入矩阵方程有 $\frac{A}{2} C_1 + \frac{A}{2} C_2 = 0 \Rightarrow C_1 = -C_2$。
   相应波函数：
   $$ \psi_- \propto e^{i (\frac{2\pi}{a}x + k_y y)} - e^{i (-\frac{2\pi}{a}x + k_y y)} = e^{i k_y y} \left( e^{i\frac{2\pi x}{a}} - e^{-i\frac{2\pi x}{a}} \right) = 2i \sin\left(\frac{2\pi x}{a}\right) e^{i k_y y} $$

**(答案总结：)**
能量为： $E_{\pm} = \frac{\hbar^2}{2m} \left( \frac{4\pi^2}{a^2} + k_y^2 \right) + V_0 \pm \frac{A}{2}$
对应的波函数（未全空间归一化前）为：
与 $E_+$ 对应: $\psi_+ \propto \cos\left(\frac{2\pi x}{a}\right) e^{i k_y y}$ （驻波，偶对称）
与 $E_-$ 对应: $\psi_- \propto \sin\left(\frac{2\pi x}{a}\right) e^{i k_y y}$ （驻波，奇对称）
