## Solution
这是一份涵盖了经典电动力学、狭义相对论以及等离子体物理的综合性物理试卷解答。以下是每道题的详细解析过程：

---

### 1. 判断题（详细解析）

**[1]. 匀速运动的带电粒子不可能辐射；**
**判断：错误（F）。**
**理由：** 虽然在真空中匀速运动的带电粒子不会产生辐射，但是当带电粒子在介质中运动，且其速度超过光在该介质中的相速度（$v > c/n$）时，会产生**切伦科夫辐射（Cherenkov radiation）**。题目表述为“不可能”，过于绝对，因此是错误的。

**[2]. 如果没有大气，天空将是黑的；**
**判断：正确（T）。**
**理由：** 我们平时看到的蓝色天空是由于太阳光在大气层中发生**瑞利散射**（波长越短散射越强，蓝光被强烈散射向四面八方）。如果没有大气层，光线将沿直线直接射到地面，除直接看太阳外，其它方向没有散射光进入人眼，天空会呈现宇宙的底色——黑色（正如宇航员在太空中看到的景象）。

**[3]. 红色光在康普顿散射实验中更显光的粒子性；**
**判断：错误（F）。**
**理由：** 康普顿散射揭示了光子具有动量，体现了光的粒子性。要使康普顿效应明显，光子的能量必须与电子的静止能量（$0.51\mathrm{MeV}$）可比拟。因此，**高频、短波长的X射线或伽马射线**能非常明显地观察到康普顿散射；而红色光频率极低、能量极小，几乎观察不到该效应，其波动性更为显著`。

**[4]. 以布儒斯特角入射的光的透射光是 $100\%$ 偏振的；**
**判断：错误（F）。**
**理由：** 当自然光以布儒斯特角入射时，**反射光**是 $100\%$ 的线偏振光（且振动方向垂直于入射面，即s偏振光）。但**透射光**只是**部分偏振光**，它包含了全部的p偏振分量和剩下未被反射的s偏振分量。

**[5]. 粒子的动质量是洛伦兹不变量。**
**判断：错误（F）。**
**理由：** 粒子的**静质量** $m_0$ 才是洛伦兹不变量。动质量 $m = \gamma m_0 = \frac{m_0}{\sqrt{1-v^2/c^2}}$ 与粒子的运动速度有关，在不同的参考系下测量到的动质量是不同的，因此不是不变量。

### 2. 狭义相对论：飞船飞行问题

已知：地球与恒星距离 $d = 5$ 光年，飞船相对地球的速度 $v = 0.8c$。此时洛伦兹因子 $\gamma = \frac{1}{\sqrt{1 - 0.8^2}} = \frac{1}{0.6} = \frac{5}{3}$。

**[1]. 地球上过了多长时间；**
对地球上的观察者而言，飞船是在测量的静止距离 $d$ 上运动，所以地球上流逝的时间就是普通的距离除以速度：
$$t_{\text{earth}} = \frac{d}{v} = \frac{5\mathrm{c \cdot year}}{0.8\mathrm{c}} = \mathbf{6.25 \text{ 年}}$$

**[2]. 宇航员过了多长时间；**
宇航员所在的参考系测量到的时间是“固有时（Proper time）”。根据相对论钟慢效应，运动的钟走得慢：
$$t_{\text{astronaut}} = \frac{t_{\text{earth}}}{\gamma} = 6.25 \times \frac{3}{5} = \mathbf{3.75 \text{ 年}}$$

**[3]. 宇航员认为地球过了多长时间。**
这个问题考察的是“同时性的相对性”。在宇航员的参考系中，他自己是静止的，而**地球正在以 $0.8c$ 的速度远离他**。
因此，宇航员认为地球上的钟变慢了。当宇航员的表过了 $3.75$ 年到达恒星时，在他认为“同时”的那个瞬间，地球上流逝的时间为：
$$t'_{\text{earth}} = \frac{t_{\text{astronaut}}}{\gamma} = 3.75 \times \frac{3}{5} = \mathbf{2.25 \text{ 年}}$$

### 3. 四维加速度与李纳公式推导

**(1) 计算与证明不变量**
四维速度定义为 $U^\mu = (\gamma c, \gamma \vec{v})$。四维加速度定义为对其固有时 $\tau$ 求导：
$$A^\mu = \frac{dU^\mu}{d\tau} = \gamma \frac{dU^\mu}{dt}$$
利用 $\frac{d\gamma}{dt} = \gamma^3 \frac{\vec{v}\cdot\vec{a}}{c^2}$，代入可得实验室系下的四维加速度分量：
$$A^0 = \gamma^4 \frac{\vec{v}\cdot\vec{a}}{c}$$
$$\vec{A} = \gamma^2 \vec{a} + \gamma^4 \frac{\vec{v}\cdot\vec{a}}{c^2} \vec{v}$$
由于 $A_\mu A^\mu = -(A^0)^2 + |\vec{A}|^2$ 是一个洛伦兹标量（不变量）。
在瞬时静止系 $S'$ 中，速度 $\vec{v}'=0$，此时 $\gamma=1$，代入上式即得瞬时静止系中的四维加速度为：
$$\mathbf{\vec{A}' = (0, \vec{a}')}$$
其内积 $(A'_\mu A'^\mu) = |\vec{a}'|^2$。由于内积是不变量，故证明了 **$(\vec{a}')^2 = A_\mu A^\mu$ 是洛伦兹不变量**。

**(2) 导出 $\vec{a}'$ 与 $\vec{a}$ 的关系并推导李纳公式**
将实验室系分量代入不变量等式：
$$(\vec{a}')^2 = \left| \gamma^2 \vec{a} + \gamma^4 \frac{\vec{v}\cdot\vec{a}}{c^2} \vec{v} \right|^2 - \left( \gamma^4 \frac{\vec{v}\cdot\vec{a}}{c} \right)^2$$
利用矢量恒等展开并合并同类项，可以化简得到：
$$(\vec{a}')^2 = \gamma^6 \left( a^2 - \frac{(\vec{v} \times \vec{a})^2}{c^2} \right)$$
在瞬时静止系中，由于速度为0，带电粒子的辐射功率可以用非相对论的经典**拉莫尔公式**准确计算：
$$P' = \frac{q^2 (\vec{a}')^2}{6\pi\varepsilon_0 c^3}$$
根据相对论能量与时间的变换性质，总辐射功率是洛伦兹不变量，即 $P = P'$。将刚才求得的 $(\vec{a}')^2$ 代入，即可得到任意速度下带电粒子的辐射功率公式——**李纳辐射公式**：
$$P = \frac{q^2 \gamma^6}{6\pi\varepsilon_0 c^3} \left( a^2 - \frac{(\vec{v} \times \vec{a})^2}{c^2} \right)$$

### 4. 四矢势变换计算运动电荷的势

设电荷 $q$ 沿 $x$ 轴以匀速 $V$ 运动。我们在伴随电荷运动的静止系 $S'$ 中观察，电荷静止在坐标原点。
在 $S'$ 系中，标势和矢势（即四维势 $A'^\mu$）为普通的库仑势：
$$\phi' = \frac{q}{4\pi\varepsilon_0 r'} = \frac{q}{4\pi\varepsilon_0 \sqrt{x'^2 + y'^2 + z'^2}}$$
$$\vec{A}' = 0$$
四维势 $A^\mu = (\phi/c, A_x, A_y, A_z)$ 作为四维逆变矢量，满足洛伦兹变换。实验室系 $S$ 相对 $S'$ 以速度 $-V$ 运动（即在 $S$ 看来 $S'$ 往 $+V$ 跑），变换关系为：
$$ \frac{\phi}{c} = \gamma \left( \frac{\phi'}{c} + \frac{V}{c} A'_x \right) $$
$$ A_x = \gamma \left( A'_x + \frac{V}{c} \frac{\phi'}{c} \right) $$
$$ A_y = A'_y = 0 , \quad A_z = A'_z = 0 $$
代入 $\vec{A}'=0$：
$$\phi = \gamma \phi'$$
$$A_x = \gamma \frac{V}{c^2} \phi' = \frac{V}{c^2} \phi \implies \mathbf{\vec{A} = \frac{\vec{V}}{c^2} \phi}$$
根据空间坐标的逆变换 $x' = \gamma(x - Vt), y'=y, z'=z$，代回 $\phi'$ 的表达式中：
$$\mathbf{\phi(x,y,z,t) = \frac{1}{4\pi\varepsilon_0} \frac{q}{\sqrt{(x - Vt)^2 + \frac{y^2 + z^2}{\gamma^2}}}}$$
这就是相对论性匀速运动电荷的**李纳-维谢尔（Liénard-Wiechert）势**。

### 5. 圆周运动粒子的偏振与辐射功率

设粒子在 $xy$ 平面内作半径为 $a$，角速度为 $\omega$ 的圆周运动。向心加速度大小为 $a_c = a\omega^2$，方向不断绕原点旋转。
由辐射电场公式 $\vec{E} \propto \vec{n} \times (\vec{n} \times \vec{a})$（$\vec{n}$ 为观察方向观测单位矢量）：
*   **$\theta = 0$ 处（沿 $z$ 轴正向观察）：** 
    此时 $\vec{n} = \hat{z}$，投影到垂直于视线的平面恰好是完整的 $xy$ 平面。加速度矢量在 $xy$ 平面内做匀速圆周旋转，因此观察到的电场也是圆周旋转的，表现为 **圆偏振光**。
*   **$\theta = \frac{\pi}{2}$ 处（在 $xy$ 平面内观察，假设沿 $x$ 轴）：** 
    此时 $\vec{n} = \hat{x}$。加速度只有投影在垂直于 $x$ 轴的方向（即 $y$ 轴方向）分量才会产生辐射。观察到的粒子加速度等效为沿 $y$ 轴的一维简谐振荡。因此，辐射表现为 **线偏振光**（偏振方向平行于轨道平面）。
*   **$\theta = \pi$ 处（沿 $z$ 轴负向观察）：** 
    类似于 $\theta=0$，但视线反转。投影仍为圆周运动，表现为 **圆偏振光**（但旋向与 $\theta=0$ 处相反）。

**平均辐射功率：**
运动的加速度大小恒定 $|a_c| = a\omega^2$。利用拉莫尔辐射公式（设非相对论极限）：
$$\mathbf{P = \frac{q^2 a_c^2}{6\pi\varepsilon_0 c^3} = \frac{q^2 a^2 \omega^4}{6\pi\varepsilon_0 c^3}}$$

### 6. 等离子体中的法拉第旋光（密度计算）

*注：题目给出 $\omega_{P} = \sqrt{\frac{n_{e}e^{2}}{m_{e}e}}$，根据量纲和物理常识，分母中的单 $e$ 明显是打字排版错误，标准公式应为 $\varepsilon_0$。下文按照标准物理定义 $\omega_p^2 = \frac{n_e e^2}{m_e \varepsilon_0}$ 计算。*

等离子体厚度 $d = 1\mathrm{m}$，磁场 $B_0 = 0.1\mathrm{T}$，波长 $\lambda_0 = 8\mathrm{mm} = 8\times 10^{-3}\mathrm{m}$。
角频率：$\omega = \frac{2\pi c}{\lambda_0} = \frac{2\pi \times 3\times 10^8}{8\times 10^{-3}} = 2.356 \times 10^{11} \mathrm{rad/s}$。
电子回旋频率：$\omega_{ce} = \frac{e B_0}{m_e} = \frac{1.6\times 10^{-19} \times 0.1}{9.1\times 10^{-31}} \approx 1.758 \times 10^{10} \mathrm{rad/s}$。

偏振面旋转角（法拉第旋转）公式为：$\Delta\theta = \frac{d}{2}(k_L - k_R)$。已知 $\Delta\theta = 90^\circ = \frac{\pi}{2}$。
代入色散关系 $k_{L/R} = \frac{\omega}{c} \left[1 - \frac{\omega_{p}^{2}}{\omega^{2}(1 \pm \frac{\omega_{ce}}{\omega})}\right]$：
$$k_L - k_R = \frac{\omega}{c} \left[ \left(1 - \frac{\omega_p^2}{\omega(\omega + \omega_{ce})}\right) - \left(1 - \frac{\omega_p^2}{\omega(\omega - \omega_{ce})}\right) \right]$$
$$k_L - k_R = \frac{\omega_p^2}{c} \left( \frac{1}{\omega - \omega_{ce}} - \frac{1}{\omega + \omega_{ce}} \right) = \frac{\omega_p^2}{c} \frac{2\omega_{ce}}{\omega^2 - \omega_{ce}^2}$$
代入旋转角公式：
$$\frac{\pi}{2} = \frac{d}{2} \frac{\omega_p^2}{c} \frac{2\omega_{ce}}{\omega^2 - \omega_{ce}^2} \implies \omega_p^2 = \frac{\pi c (\omega^2 - \omega_{ce}^2)}{2 d \omega_{ce}}$$
代入数值：
$\omega^2 - \omega_{ce}^2 = (2.356 \times 10^{11})^2 - (1.758 \times 10^{10})^2 \approx 5.55 \times 10^{22} - 3.09 \times 10^{20} \approx 5.52 \times 10^{22} \mathrm{(rad/s)^2}$
$$\omega_p^2 = \frac{\pi \times 3\times 10^8 \times 5.52 \times 10^{22}}{2 \times 1 \times 1.758 \times 10^{10}} \approx 1.48 \times 10^{21} \mathrm{(rad/s)^2}$$
求电子密度 $n_e$：
$$n_e = \frac{m_e \varepsilon_0 \omega_p^2}{e^2} = \frac{9.1\times 10^{-31} \times 8.85\times 10^{-12} \times 1.48\times 10^{21}}{(1.6\times 10^{-19})^2} \approx \mathbf{4.65 \times 10^{18} \text{ m}^{-3}}$$

### 7. 相对论多普勒效应

> [!NOTE] Note
> 值得注意的是我们必须清楚波矢就是光传播的一个特定方向，因此观察的角度决定了波矢的方向。
> 这里和一般的小球运动不同，**因为光的传播方向是由我们特定的观察给定的**


设原子速度为 $v$（注：题干中符号 $\nu$ 应为排版错误，为避免与频率混淆，公式中用 $v$ 表示速度），$\beta = \frac{v}{c}$，$\gamma = \frac{1}{\sqrt{1-\beta^2}}$。频率变换通式为 $f = f_0 \frac{\sqrt{1-\beta^2}}{1-\beta\cos\theta}$，对应波长通式为 $\lambda = \lambda_0 \frac{1-\beta\cos\theta}{\sqrt{1-\beta^2}} = \lambda_0 \gamma (1-\beta\cos\theta)$。

**[1]. 顺着 $v$（纵向，迎面靠近观察）：** 
此时光源朝向观察者运动，$\theta = 0^\circ, \cos\theta = 1$。
$$\mathbf{\lambda = \lambda_0 \gamma (1-\beta) = \lambda_0 \sqrt{\frac{1-\beta}{1+\beta}}}$$ （发生蓝移，波长变短）

**[2]. 逆着 $v$（纵向，背离观察）：** 
此时光源远离观察者，$\theta = 180^\circ, \cos\theta = -1$。
$$\mathbf{\lambda = \lambda_0 \gamma (1+\beta) = \lambda_0 \sqrt{\frac{1+\beta}{1-\beta}}}$$ （发生红移，波长变长）

**[3]. 垂直 $v$（横向）：** 
此时观察方向与运动方向垂直，$\theta = 90^\circ, \cos\theta = 0$。这是由于相对论时间膨胀造成的纯相对论效应。
$$\mathbf{\lambda = \lambda_0 \gamma = \frac{\lambda_0}{\sqrt{1-\beta^2}}}$$ （发生横向红移）

### 8. 因果关系的传递性问题（画图简述）

**结论：不一定有因果关系。**

**画图与简述证明：**
我们可以画一个“闵可夫斯基时空图（光锥图）”来直观解释：
1. 以事件A为时空原点 $(x=0, t=0)$ 画一个向上的“未来光锥”。
2. 因为AB有因果关系且AC有因果关系，意味着事件B和事件C都必须落在事件A的未来光锥之内（类时或类光区域）。
3. 假设我们在图上挑选两个点：
   *   **事件 B** 落在坐标轴的左半边，比如位置 $(x=-1, t=2)$。
   *   **事件 C** 落在坐标轴的右半边，比如位置 $(x=1, t=2)$。
   *   显然，这两个事件从A触发（$c\Delta t > |\Delta x|$），完全满足AB和AC有因果关系。
4. 但是，现在我们独立考察 B 与 C 之间的关系。它们之间的时间跨度 $\Delta t_{BC} = 2 - 2 = 0$，而空间跨度 $\Delta x_{BC} = 1 - (-1) = 2$。
5. 此时 $c|\Delta t_{BC}| < |\Delta x_{BC}|$，说明 **BC 之间是“类空（Spacelike）”间隔**。没有任何信号能从 B 传递到 C 或从 C 传递到 B，它们**没有因果关系**。

### 9. 附加题：高斯光束自聚焦与抗散开机制

**原理解释：**
真空中高斯光束受瑞利衍射定律支配，一定会随传输距离发生横向散开。但在等离子体中传播极高强度的相对论级激光时，会产生**相对论自聚焦（Relativistic Self-Focusing）**效应。

1. **光强分布：** 高斯光束的能量集中在横截面的中心，边缘光强较弱。
2. **相对论质量膨胀：** 在极高强度的电场作用下，光束中心的电子被加速到接近光速，动能极大。由于相对论效应，电子的动质量（$\gamma_e m_e$）显著增加。即**光束中心区域的 $\gamma_e$ 大，边缘区域的 $\gamma_e$ 小**。
3. **等离子体频率改变：** 根据公式 $\omega_P^2 = \frac{n_e e^2}{m_e \gamma_e \varepsilon_0}$，由于中心的 $\gamma_e$ 变大，导致**光束中心局部的等离子体频率 $\omega_P$ 降低**。
4. **折射率形成“透镜”：** 根据色散关系 $\omega^2 = \omega_P^2 + k^2 c^2$，等离子体的折射率可表示为 $n = \frac{kc}{\omega} = \sqrt{1 - \frac{\omega_P^2}{\omega^2}}$。
   由于中心的 $\omega_P$ 小于边缘，导致**光束中心的折射率 $n$ 大于边缘的折射率**。
5. **结论：** 这种“中心折射率大、边缘折射率小”的折射率分布，相当于在等离子体中实时烧刻出了一个**正透镜（或凸透镜/光纤结构）**。这个相对论透镜的汇聚效应恰好可以抵消光束的横向瑞利散开效应。当两者平衡时，高斯光束就能长距离穿过等离子体而不发生横向散开。
