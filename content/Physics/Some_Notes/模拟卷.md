# 试卷一 解答

### 第 1 题：微正则与正则系综——二能级系统
**(a) 微正则配分函数 $\Omega(E, N)$**
设系统中有 $M$ 个粒子处于激发态，$(N-M)$ 个粒子处于基态。
总能量 $E = M(+\epsilon/2) + (N-M)(-\epsilon/2) = (2M - N)\epsilon/2$。
由此可解得激发态粒子数 $M = \frac{E}{\epsilon} + \frac{N}{2}$。
系统的微观状态数即为从 $N$ 个粒子中选出 $M$ 个处于激发态的组合数：
$$\Omega(E, N) = \frac{N!}{M!(N-M)!} = \frac{N!}{\left(\frac{N}{2}+\frac{E}{\epsilon}\right)! \left(\frac{N}{2}-\frac{E}{\epsilon}\right)!}$$

**(b) 正则配分函数 $Z(\beta, N)$**
由于粒子是独立的，系统的正则配分函数是单粒子配分函数 $Z_1$ 的 $N$ 次方。
单粒子配分函数 $Z_1 = e^{-\beta(-\epsilon/2)} + e^{-\beta(+\epsilon/2)} = e^{\beta\epsilon/2} + e^{-\beta\epsilon/2} = 2\cosh(\beta\epsilon/2)$。
总配分函数 $Z(\beta, N) = (Z_1)^N = \left[ 2\cosh\left(\frac{\beta\epsilon}{2}\right) \right]^N$。

**(c) 平均能量 $u$ 及热容 $C_V$**
总平均能量 $\langle E \rangle = -\frac{\partial \ln Z}{\partial \beta} = -N \frac{\partial}{\partial \beta} \ln\left[2\cosh\left(\frac{\beta\epsilon}{2}\right)\right] = -N \frac{\epsilon}{2} \tanh\left(\frac{\beta\epsilon}{2}\right)$。
每个粒子的平均能量 $u = \frac{\langle E \rangle}{N} = -\frac{\epsilon}{2} \tanh\left(\frac{\epsilon}{2T}\right)$。
热容 $C_V = \frac{\partial \langle E \rangle}{\partial T} = \frac{\partial \langle E \rangle}{\partial \beta} \frac{d\beta}{dT} = \left( -N\left(\frac{\epsilon}{2}\right)^2 \text{sech}^2\left(\frac{\beta\epsilon}{2}\right) \right) \left(-\frac{1}{T^2}\right) = N \frac{\epsilon^2}{4T^2} \text{sech}^2\left(\frac{\epsilon}{2T}\right)$。

**(d) 能量方差及证明 $\text{Var}(E) = T^2 C_V$**
能量方差 $\text{Var}(E) = \langle E^2 \rangle - \langle E \rangle^2 = \frac{\partial^2 \ln Z}{\partial \beta^2} = -\frac{\partial \langle E \rangle}{\partial \beta}$。
由于 $C_V = \frac{\partial \langle E \rangle}{\partial T} = \frac{\partial \langle E \rangle}{\partial \beta} \frac{d\beta}{dT} = -\frac{1}{T^2} \frac{\partial \langle E \rangle}{\partial \beta}$，
显然可以得到：$\text{Var}(E) = -\left( -T^2 C_V \right) = T^2 C_V$。

**(e) 高低温极限**
*   **低温极限 $T \to 0$ ($\beta \to \infty$)**：$\tanh(\infty) = 1$，因此 $u \to -\epsilon/2$。所有粒子都冻结在基态。
*   **高温极限 $T \to \infty$ ($\beta \to 0$)**：$\tanh(0) = 0$，因此 $u \to 0$。粒子在基态和激发态的占据概率相等，平均能量为两能级的中点 0。

### 第 2 题：热力学势与基本关系
**(a) 求内能 $E(S, V, N)$**
已知 $S = N \log\left(\frac{V-b}{N}\right) + \alpha N \log\left(\frac{E}{N}\right) + \gamma N$。
解出 $\log(E/N)$ 项：$\alpha N \log\left(\frac{E}{N}\right) = S - N \log\left(\frac{V-b}{N}\right) - \gamma N$。
化简得内能表达式：$E(S, V, N) = N \exp\left[ \frac{S}{\alpha N} - \frac{1}{\alpha}\log\left(\frac{V-b}{N}\right) - \frac{\gamma}{\alpha} \right]$。

**(b) Helmholtz 自由能 $F(T, V, N)$**
温度 $T = \left(\frac{\partial E}{\partial S}\right)_{V,N} = \frac{1}{\alpha N} E \implies E = \alpha N T$。
将 $E = \alpha N T$ 代入原熵函数，得到 $S(T, V, N) = N \log\left(\frac{V-b}{N}\right) + \alpha N \log(\alpha T) + \gamma N$。
自由能 $F = E - TS = \alpha N T - N T \left[ \log\left(\frac{V-b}{N}\right) + \alpha \log(\alpha T) + \gamma \right]$。

**(c) Gibbs 自由能 $G(T, P, N)$**
状态方程：$P = -\left(\frac{\partial F}{\partial V}\right)_{T,N} = \frac{N T}{V-b} \implies V - b = \frac{N T}{P} \implies V = \frac{N T}{P} + b$。
$G = F + PV$。将 $V$ 和 $\frac{V-b}{N} = \frac{T}{P}$ 代入 $F$ 中：
$F = \alpha N T - N T \left[ \log\left(\frac{T}{P}\right) + \alpha \log(\alpha T) + \gamma \right]$。
而 $PV = P\left(\frac{NT}{P} + b\right) = N T + P b$。
$G = F + PV = N T(1+\alpha) + P b - N T \left[ \log\left(\frac{T}{P}\right) + \alpha \log(\alpha T) + \gamma \right]$。

**(d) 化学势 $\mu(T, P)$**
由于 $G$ 是广延量，$\mu = \frac{G}{N}$，
$\mu(T, P) = T(1+\alpha-\gamma) + \frac{Pb}{N} - T \left[ \log\left(\frac{T}{P}\right) + \alpha \log(\alpha T) \right]$。

**(e) 巨热力学势 $\Phi(T, V, \mu)$**
巨势 $\Phi = F - \mu N = -PV$。
由状态方程 $P = \frac{NT}{V-b}$，得到 $\Phi = -PV = -\frac{NTV}{V-b}$。（若需纯用 $\mu, T, V$ 表示，需从(d)中反解出 $N(\mu)$ 代入，由于解析解复杂，通常写到 $\Phi = -PV$ 并指出状态方程即可）。

**(f) 状态方程 $P(V, T)$**
在(c)中已求出：$P = -\left(\frac{\partial F}{\partial V}\right)_{T,N} = \frac{N T}{V-b}$，即 $P(V-b) = NT$ (类似具有排斥体积的一维理想气体或刚球气体方程)。

### 第 3 题：Gibbs 相律
**(a) 证明 Gibbs 相律**
对于包含 $K$ 个组分、$r$ 个共存相的系统，描述每个相的状态需要温度 $T$、压强 $P$ 以及 $(K-1)$ 个摩尔分数。因此 $r$ 个相共有 $2 + r(K-1)$ 个状态参量。
热力学平衡要求每个组分在各相中的化学势相等：$\mu_i^{(1)} = \mu_i^{(2)} = \dots = \mu_i^{(r)}$，对 $K$ 个组分共有 $K(r-1)$ 个限制方程。
自由度 $f = \text{变量总数} - \text{方程总数} = [2 + r(K-1)] - K(r-1) = K - r + 2$。

**(b) 具体计算**
*   单组分系统 ($K=1$)：$f = 1 - r + 2 = 3 - r$。由于 $f \ge 0$，故 $r \le 3$。最多可以有 **3** 个相共存（三相点）。
*   三组分系统 ($K=3$)，两相共存 ($r=2$)：自由度 $f = 3 - 2 + 2 = 3$。

### 第 4 题：van der Waals 流体与一级相变
**(a) 旋节线 (Spinodal)**
旋节线条件为等温压缩率发散，即 $\left(\frac{\partial P}{\partial v}\right)_T = 0$。
$\frac{\partial P}{\partial v} = -\frac{T}{(v-b)^2} + \frac{2a}{v^3} = 0$。
解得旋节线温度 $T_{sp}(v) = \frac{2a(v-b)^2}{v^3}$。
将 $T_{sp}$ 代回状态方程得到旋节线压强 $P_{sp}(v) = \frac{2a(v-b)}{v^3} - \frac{a}{v^2} = \frac{a(v-2b)}{v^3}$。

**(b) 临界点**
临界点不仅满足 $\frac{\partial P}{\partial v} = 0$，还满足 $\frac{\partial^2 P}{\partial v^2} = 0$。
$\frac{\partial^2 P}{\partial v^2} = \frac{2T}{(v-b)^3} - \frac{6a}{v^4} = 0$。
将 $T = \frac{2a(v-b)^2}{v^3}$ 代入二阶导数方程：
$\frac{4a(v-b)^2}{v^3(v-b)^3} = \frac{6a}{v^4} \implies \frac{4}{v-b} = \frac{6}{v} \implies 4v = 6v - 6b \implies v_c = 3b$。
代回 $T$ 和 $P$：$T_c = \frac{2a(2b)^2}{(3b)^3} = \frac{8a}{27Rb}$ (由于 $k_B=1$)，$P_c = \frac{a(3b-2b)}{(3b)^3} = \frac{a}{27b^2}$。

**(c) Maxwell 等面积构造**
在 $T < T_c$ 时，vdw 等温线在中间区域会出现 $\partial P/\partial v > 0$（非物理）。真实系统的共存压强 $P_{coex}$ 是一条水平线。热力学平衡要求两相吉布斯自由能相等 $g_l = g_g$，即 $\int_{v_l}^{v_g} v dP = 0$。在 P-v 图上，这意味着水平线 $P = P_{coex}$ 割除的上下两个面积相等：$\int_{v_l}^{v_g} (P_{vdw}(v) - P_{coex}) dv = 0$。

**(d) P-v 平面区域**
*   **稳定区域**：双节线 (Binodal，即共存曲线) 的外侧。
*   **亚稳区域**：双节线与旋节线 (Spinodal) 之间的区域（如过热液体、过冷蒸汽）。
*   **不稳定区域**：旋节线内部（满足 $\partial P/\partial v > 0$），系统会发生 spinodal 分解，自发相分离。

### 第 5 题：Landau 理论与临界现象
**(a) 平衡磁化强度 $m_0(T)$**
平衡条件为自由能取极小值：$\frac{\partial f}{\partial m} = a(T-T_c)m + bm^3 = 0 \implies m[a(T-T_c) + bm^2] = 0$。
*   $T > T_c$ 时，$a(T-T_c) > 0$，唯一实数解为 $m_0 = 0$。
*   $T < T_c$ 时，$m=0$ 是极大值，极小值对应 $a(T-T_c) + bm^2 = 0 \implies m_0 = \pm \sqrt{\frac{a(T_c-T)}{b}}$。

**(b) 零场磁化率 $\chi_T$**
加上外场 $h$ 后，$f_{new} = f - hm$。极值条件变为 $a(T-T_c)m + bm^3 = h$。
两边对 $h$ 求导：$a(T-T_c)\chi_T + 3bm^2 \chi_T = 1 \implies \chi_T = \frac{1}{a(T-T_c) + 3bm^2}$。
在 $T \to T_c^+$ 且 $h=0$ 时，$m_0=0$，因此 $\chi_T = \frac{1}{a(T-T_c)}$。
行为：在逼近临界点时，磁化率按规律发散（发散趋于无穷大）。

**(c) 临界指数推导**
*   由(a)知 $T<T_c$ 时 $m_0 = \sqrt{\frac{a}{b}}(T_c-T)^{1/2}$，故 $\beta = 1/2$。
*   由(b)知 $T>T_c$ 时 $\chi_T = a^{-1}(T-T_c)^{-1}$，故 $\gamma = 1$。
*   在 $T=T_c$ 时，状态方程变为 $bm^3 = h \implies m = (1/b)^{1/3} h^{1/3}$，故 $\delta = 3$。

# 试卷二 解答

### 第 1 题：正则系综——量子谐振子
**(a) 单个谐振子配分函数 $Z_1(\beta)$**
$Z_1 = \sum_{n_x, n_y, n_z = 0}^\infty e^{-\beta \hbar\omega (n_x+n_y+n_z+3/2)}$。
由于三个自由度相互独立，可分解为一维配分函数的立方：
$Z_1 = \left[ \sum_{n=0}^\infty e^{-\beta \hbar\omega (n+1/2)} \right]^3 = \left[ \frac{e^{-\beta \hbar\omega/2}}{1 - e^{-\beta \hbar\omega}} \right]^3 = \frac{1}{[2\sinh(\beta\hbar\omega/2)]^3}$。

**(b) 整个系统的配分函数 $Z_N(\beta)$**
假设谐振子被固定在晶格上因而是可分辨的，系统的总配分函数为：
$Z_N = (Z_1)^N = \left[ 2\sinh\left(\frac{\beta\hbar\omega}{2}\right) \right]^{-3N}$。

**(c) 平均内能 $U(T)$ 与热容 $C_V(T)$**
$U = -\frac{\partial \ln Z_N}{\partial \beta} = 3N \frac{\partial}{\partial \beta} \ln\left[ 2\sinh\left(\frac{\beta\hbar\omega}{2}\right) \right] = \frac{3N\hbar\omega}{2} \coth\left(\frac{\beta\hbar\omega}{2}\right)$。
$C_V = \frac{\partial U}{\partial T} = \frac{\partial U}{\partial \beta}\frac{d\beta}{dT} = 3N \left( \frac{\hbar\omega}{2} \right) \left(-\text{csch}^2\left(\frac{\beta\hbar\omega}{2}\right) \cdot \frac{\hbar\omega}{2}\right) \left(-\frac{1}{T^2}\right) = 3N \left(\frac{\hbar\omega}{2T}\right)^2 \frac{1}{\sinh^2(\frac{\hbar\omega}{2T})}$。

**(d) 高温极限 $T \gg \hbar\omega$**
此时 $x = \beta\hbar\omega/2 \ll 1$。$\coth(x) \approx 1/x$。
$U \approx \frac{3N\hbar\omega}{2} \cdot \frac{2}{\beta\hbar\omega} = \frac{3N}{\beta} = 3NT$。
比较：经典能量均分定理指出，每个二次型自由度贡献 $T/2$。三维谐振子有 3 个动能二次项和 3 个势能二次项，共计 6 个。$6 \times \frac{1}{2}NT = 3NT$，与量子高温极限结果完全一致。

**(e) 低温极限 $T \ll \hbar\omega$**
此时 $x = \beta\hbar\omega/2 \gg 1$。$\sinh(x) \approx \frac{e^x}{2}$。
$C_V = 3N x^2 \frac{1}{(e^x/2)^2} = 12 N \left(\frac{\hbar\omega}{2T}\right)^2 e^{-\hbar\omega/T} = 3N \left(\frac{\hbar\omega}{T}\right)^2 e^{-\hbar\omega/T}$。
可见当 $T \to 0$ 时，$C_V \propto (1/T^2) e^{-\text{const}/T} \to 0$。这与热力学第三定律（当系统趋于绝对零度时，热容必须趋于零）是一致的。

### 第 2 题：热力学势的 Legendre 变换
**(a) 熵 $S(T, V, N)$ 与内能 $U(T, V, N)$**
$F = -NT \ln\left[ \frac{V}{N} \left(\frac{T}{T_0}\right)^{3/2} \right] + NT$。
$S = -\left(\frac{\partial F}{\partial T}\right)_{V,N} = N \ln\left[ \frac{V}{N} \left(\frac{T}{T_0}\right)^{3/2} \right] + NT \left( \frac{3/2}{T} \right) - N = N \ln\left[ \frac{V}{N} \left(\frac{T}{T_0}\right)^{3/2} \right] + \frac{1}{2}N$。
内能 $U = F + TS = NT + \frac{1}{2}NT = \frac{3}{2}NT$。（这是单原子理想气体的内能形式）。

**(b) 熵表示为 $S(U, V, N)$**
由上可知 $T = \frac{2U}{3N}$，代入 $S$ 中：
$S(U, V, N) = N \ln\left[ \frac{V}{N} \left(\frac{2U}{3NT_0}\right)^{3/2} \right] + \frac{1}{2}N$。

**(c) 焓 $H(S, P, N)$**
$P = -\left(\frac{\partial F}{\partial V}\right)_{T,N} = \frac{NT}{V}$。故 $PV = NT = \frac{2}{3}U$。
焓 $H = U + PV = U + \frac{2}{3}U = \frac{5}{3}U$（或写为 $H = \frac{5}{2}NT$）。
若需表示为 $S, P, N$ 的函数，利用 $V/N = T/P$，
$S = \frac{5}{2}N\ln T - N\ln P + N\ln\left(T_0^{-3/2}\right) + \frac{1}{2}N \implies T(S,P) = \dots \implies H = \frac{5}{2}NT(S,P)$。

**(d) Gibbs 自由能 $G(T, P, N)$**
$G = F + PV = F + NT = -NT \ln\left[ \frac{V}{N} \left(\frac{T}{T_0}\right)^{3/2} \right] + 2NT$。
代入 $V/N = T/P$，得 $G(T, P, N) = -NT \ln\left[ \frac{T^{5/2}}{P T_0^{3/2}} \right] + 2NT$。

**(e) 导出 Maxwell 关系及验证**
由微分关系式 $dF = -SdT - PdV$。因为二阶偏导数与求导顺序无关，$\frac{\partial^2 F}{\partial V \partial T} = \frac{\partial^2 F}{\partial T \partial V}$。
所以 $\left(\frac{\partial S}{\partial V}\right)_{T,N} = -\frac{\partial^2 F}{\partial V \partial T}$，而 $\left(\frac{\partial P}{\partial T}\right)_{V,N} = -\frac{\partial^2 F}{\partial T \partial V}$，故得证 $\left(\frac{\partial S}{\partial V}\right)_T = \left(\frac{\partial P}{\partial T}\right)_V$。
验证：对上述系统，$\left(\frac{\partial S}{\partial V}\right)_T = \frac{\partial}{\partial V} [N\ln V + \dots] = \frac{N}{V}$。
状态方程为 $P = \frac{NT}{V}$，$\left(\frac{\partial P}{\partial T}\right)_V = \frac{N}{V}$。等式显然成立。

**(f) 化学势 $\mu(T, P)$**
$\mu = \frac{G}{N} = -T \ln\left[ \frac{T^{5/2}}{P T_0^{3/2}} \right] + 2T$。

### 第 3 题：Clapeyron 方程
**(a) 推导方程**
沿相共存曲线，两相的化学势必须时刻相等：$\mu_1(T, P) = \mu_2(T, P)$。
当沿共存曲线产生微小变化 $(dT, dP)$ 时：$d\mu_1 = d\mu_2$。
根据基本方程 $d\mu = -s dT + v dP$（小写为单粒子量）：
$-s_1 dT + v_1 dP = -s_2 dT + v_2 dP \implies (v_2 - v_1) dP = (s_2 - s_1) dT$。
由于潜热 $L = T(s_2 - s_1)$，代入可得 $\frac{dP}{dT} = \frac{s_2 - s_1}{v_2 - v_1} = \frac{L/T}{\Delta v} = \frac{L}{T\Delta v}$。

**(b) 冰点的负斜率及其物理意义**
水从固态（冰）融化为液态（水）时，吸收潜热（$L > 0$），但冰融化时体积会缩小，即液态的摩尔体积小于固态（$\Delta v = v_{liq} - v_{sol} < 0$）。
因此，Clapeyron 方程给出的斜率 $dP/dT$ 为负值。
物理意义：外界压强增加时，系统倾向于转变为体积更小（密度更大）的相（即水）。因此，加压会导致冰的熔点 $T$ 降低（复冰现象）。

### 第 4 题：一级相变与相分离
**(a) 旋节线温度 $T_s(x)$**
稳定性边界为 $\left(\frac{\partial^2 f}{\partial x^2}\right)_T = 0$。
$f(x,T) = \frac{a}{2}(T-T_*)x^2 + \frac{b}{4}x^4$。
$\frac{\partial^2 f}{\partial x^2} = a(T-T_*) + 3bx^2 = 0$。解得 $T_s(x) = T_* - \frac{3b}{a}x^2$。

**(b) 相分离组成 $x_1, x_2$**
共存相满足公切线条件：偏导数相等且截距相等。由于 $f(x)$ 关于 $x=0$ 对称（只有偶次项），其两相共存必然发生在两个对称的极小值点处。
$\frac{\partial f}{\partial x} = a(T-T_*)x + bx^3 = 0$。
当 $T < T_*$ 时，非零解为 $x_1 = -\sqrt{\frac{a(T_*-T)}{b}}$ 和 $x_2 = \sqrt{\frac{a(T_*-T)}{b}}$。这即为共存两相的浓度。

**(c) T-x 平面区域**
*   **Binodal 曲线**：$T = T_* - \frac{b}{a}x^2$（即上面求得的 $x_1, x_2$ 反解的边界）。
*   **Spinodal 曲线**：$T = T_* - \frac{3b}{a}x^2$（开口更窄的抛物线）。
*   不稳定区域为 Spinodal 内部；亚稳区域为 Binodal 与 Spinodal 之间的夹带。

**(d) 为什么 $T = T_*$ 是临界温度及序参量行为**
当 $T \ge T_*$ 时，唯一的平衡态极小值点是 $x = 0$（单相，合金均匀）。
当 $T < T_*$ 时，系统分为 $x_1$ 和 $x_2$ 两相。$T_*$ 是相分离发生的最高温度，因此是临界温度。
当 $T$ 从下方逼近 $T_*$ 时，序参量 $\Delta x = x_2 = \sqrt{\frac{a}{b}}(T_*-T)^{1/2}$。即表现出典型的连续相变行为，临界指数 $\beta = 1/2$。

### 第 5 题：系综等价性与涨落
**(a) 热力学极限下的系综等价性**
在热力学极限（$N \to \infty, V \to \infty$，密度恒定）下，宏观涨落相对于平均值的比例衰减为 $1/\sqrt{N} \to 0$。系统物理量在均值附近表现出极尖锐的 $\delta$ 函数分布。因此，无论系统是能量完全孤立（微正则）、受热库恒温控制（正则）还是受粒子源恒 $\mu$ 控制（巨正则），其计算出的关于强度的物态方程（压强、化学势等）均是渐进相等的（误差在热力学极限下严格为 0）。

**(b) 正则系综的能量涨落**
由第一题知 $\text{Var}(E) = \langle E^2 \rangle - \langle E \rangle^2 = T^2 C_V$。
由于 $C_V$ 和 $\langle E \rangle$ 均为广延量，正比于粒子数 $N$。
故相对涨落宽度 $\frac{\sqrt{\text{Var}(E)}}{\langle E \rangle} \sim \frac{\sqrt{N}}{N} = \frac{1}{\sqrt{N}}$。
这说明在 $N \sim 10^{23}$ 时，能量的相对偏差在 $10^{-11}$ 量级，对于宏观测量而言，可以认为能量具有一个完全确定的单一值，表现出确定性的热力学行为。

**(c) 巨正则系综的粒子数涨落及临界点行为**
巨正则系综中平均粒子数 $\langle N \rangle = \frac{\partial \ln \Xi}{\partial (\beta\mu)}$。
粒子数方差 $\text{Var}(N) = \frac{\partial^2 \ln \Xi}{\partial (\beta\mu)^2} = \frac{\partial \langle N \rangle}{\partial (\beta\mu)} = \frac{1}{\beta} \left(\frac{\partial \langle N \rangle}{\partial \mu}\right)_{T,V} = T \left(\frac{\partial \langle N \rangle}{\partial \mu}\right)_{T,V}$。
**临界点行为**：由热力学关系可知，$\left(\frac{\partial N}{\partial \mu}\right)_{T,V} = \frac{N^2}{V} \kappa_T$（$\kappa_T$ 为等温压缩率）。在气液相变的临界点，等温压缩率 $\kappa_T \to \infty$。导致 $\text{Var}(N) \to \infty$，系统出现巨大的宏观密度涨落，这也是产生“临界乳光”现象的原因。

# 试卷三 解答

### 第 1 题：巨正则系综——理想费米气体
**(a) 巨配分函数及分解原因**
$\Xi(T, V, \mu) = \prod_{k} \left( 1 + e^{-\beta(\epsilon_k - \mu)} \right)^{g_s}$。
**分解原因**：由于是无相互作用理想气体，系统总哈密顿量为单粒子哈密顿量之和。在巨正则系综下，对多体构型求和可以严格转化为对每个单粒子能态 $k$ 的占据数 ($n_k = 0$ 或 $1$) 进行独立求和之积。

**(b) 零温化学势 $\mu(0)$ 与密度的关系**
在 $T=0$ 时，费米-狄拉克分布退化为阶跃函数，系统填满直到费米能级 $\epsilon_F$ 的所有态。$\mu(0) = \epsilon_F$。
态密度 $g(\epsilon) = g_s \frac{V}{(2\pi)^3} 4\pi k^2 \frac{dk}{d\epsilon} = \frac{g_s V}{4\pi^2} \left(\frac{2m}{\hbar^2}\right)^{3/2} \epsilon^{1/2}$。
总粒子数 $N = \int_0^{\epsilon_F} g(\epsilon) d\epsilon = \frac{g_s V}{4\pi^2} \left(\frac{2m}{\hbar^2}\right)^{3/2} \frac{2}{3} \epsilon_F^{3/2}$。
解得 $\mu(0) = \epsilon_F = \frac{\hbar^2}{2m} \left( \frac{6\pi^2 n}{g_s} \right)^{2/3}$ （其中 $n=N/V$，对电子 $g_s=2$ 即可退化为标准公式）。

**(c) $T=0$ 时的内能 $U_0$ 和压强 $P_0$**
$U_0 = \int_0^{\epsilon_F} \epsilon g(\epsilon) d\epsilon = \frac{g_s V}{4\pi^2} \left(\frac{2m}{\hbar^2}\right)^{3/2} \frac{2}{5} \epsilon_F^{5/2}$。
注意到 $U_0$ 与 $N$ 的积分关系，有 $U_0 = \frac{3}{5} N \epsilon_F$。
非相对论理想气体的压强公式为 $P V = \frac{2}{3} U$，故 $P_0 = \frac{2}{3} \frac{U_0}{V} = \frac{2}{5} n \epsilon_F$。

**(d) 低温热容 $C_V$ 推导**
低温下，利用 Sommerfeld 展开，$U(T) \approx U_0 + \frac{\pi^2}{6} T^2 g(\epsilon_F)$。
对 $T$ 求导得热容 $C_V = \frac{\pi^2}{3} T g(\epsilon_F)$。
由(b)中 $N = \frac{2}{3} \epsilon_F g(\epsilon_F)$ 可知 $g(\epsilon_F) = \frac{3N}{2\epsilon_F}$。
代入得 $C_V = \frac{\pi^2}{3} T \left( \frac{3N}{2\epsilon_F} \right) = \frac{\pi^2}{2} N \frac{T}{\epsilon_F}$。

**(e) “简并压”的物理起源及白矮星抗塌缩**
**起源**：简并压起源于量子力学的泡利不相容原理（Pauli exclusion principle）。由于费米子不能处于相同的量子态，即使在绝对零度，大量费米子也被迫占据高动量能态，从而产生巨大的宏观零点动能，对外表现为强大的宏观排斥压强。
**应用**：在白矮星中，引力试图将恒星物质无限压缩。当物质被压缩极密时，其中的电子成为深度简并的费米气体，由此产生极大的电子简并压（正比于 $n^{5/3}$）。正是这个由于纯量子效应产生的压强抗衡了引力，维持了白矮星的稳定结构。

### 第 2 题：热力学函数与稳定性
**(a) 导出基本状态量**
$U(S, V, N) = A \frac{S^2}{N} + B \frac{N^2}{V}$。
$T = \left(\frac{\partial U}{\partial S}\right)_{V,N} = \frac{2A S}{N}$。
$P = -\left(\frac{\partial U}{\partial V}\right)_{S,N} = \frac{B N^2}{V^2}$。
$\mu = \left(\frac{\partial U}{\partial N}\right)_{S,V} = -A\frac{S^2}{N^2} + 2B\frac{N}{V}$。

**(b) 熵函数 $S(T, V, N)$ 及其凹性**
由 $T = \frac{2A S}{N}$ 得 $S(T, V, N) = \frac{N T}{2A}$。
（注意：这要求将本题给定的 $U$ 反解。熵 $S = \sqrt{\frac{N}{A}\left(U - B\frac{N^2}{V}\right)}$，计算其关于 $U$ 的二阶导数 $\frac{\partial^2 S}{\partial U^2} = -\frac{1}{4} \left(\frac{N}{A}\right)^2 (\dots)^{-3/2} < 0$，证明了其为凹函数）。

**(c) Helmholtz 自由能 $F(T, V, N)$**
$F = U - TS$。将 $S = \frac{N T}{2A}$ 代入 $U$：
$U = A\frac{(NT/2A)^2}{N} + \frac{B N^2}{V} = \frac{N T^2}{4A} + \frac{B N^2}{V}$。
$TS = T \left( \frac{N T}{2A} \right) = \frac{N T^2}{2A}$。
$F = U - TS = -\frac{N T^2}{4A} + \frac{B N^2}{V}$。

**(d) 定容与定压热容**
定容热容 $C_V = T \left(\frac{\partial S}{\partial T}\right)_V = T \left( \frac{N}{2A} \right) = \frac{NT}{2A}$。
定压热容 $C_P = T \left(\frac{\partial S}{\partial T}\right)_P$。由于状态方程 $P = B(N/V)^2$ 中压强 $P$ 仅取决于体积，与温度完全解耦。在恒定 $P$ 发生温度微扰时，体积 $V$ 不发生变化（热膨胀系数 $\alpha = 0$）。因此系统不向外做功，热量完全用于增加内能：$C_P = C_V = \frac{NT}{2A}$。
由于 $A>0, T>0$，满足 $C_P \ge C_V > 0$（严格而言对该特殊模型 $C_P = C_V$）。

**(e) 等温与绝热压缩率**
$P = B N^2 V^{-2} \implies V = N \sqrt{B} P^{-1/2}$。
等温压缩率 $\kappa_T = -\frac{1}{V}\left(\frac{\partial V}{\partial P}\right)_T = -\frac{1}{V} \left( -\frac{1}{2} N\sqrt{B} P^{-3/2} \right) = \frac{1}{2P}$。
绝热压缩率 $\kappa_S$ 同理，因 $P$ 不依赖于 $S$，故 $\kappa_S = \kappa_T = \frac{1}{2P} > 0$。

**(f) 热力学稳定性讨论**
热力学稳定的充要条件是 $C_V > 0$ 以及 $\kappa_T > 0$。
前文已证：$C_V = \frac{NT}{2A} > 0$ （因为 $A>0, T>0$）。
$\kappa_T = \frac{1}{2P} = \frac{V^2}{2BN^2} > 0$ （因为 $B>0$）。
因此，条件满足，该系统在所有参数空间均热力学稳定。

### 第 3 题：混合熵与理想溶液
**(a) 混合熵推导**
混合前，两气体满足 $P, T$ 相同。理想气体单组分熵 $S_i = N_i \log(V_i/N_i) + N_i f(T)$。
由于温压相同，$V_A/N_A = V_B/N_B = V/N$。
初态总熵 $S_{initial} = N_A \log(V/N) + N_A f(T) + N_B \log(V/N) + N_B f(T)$。
混合后，每种气体扩散至总体积 $V$，行为互不干扰：
$S_{final} = N_A \log(V/N_A) + N_A f(T) + N_B \log(V/N_B) + N_B f(T)$。
混合熵 $\Delta S_{mix} = S_{final} - S_{initial} = N_A \log(V/V_A) + N_B \log(V/V_B)$。
定义 $x = N_A/N = V_A/V$，则 $1-x = N_B/N = V_B/V$。
代入得 $\Delta S_{mix} = -N_A \log x - N_B \log(1-x) = -N [x \log x + (1-x)\log(1-x)]$。

**(b) 物理讨论与 Gibbs 佯谬**
*   **广延量性质**：从上式明显看出 $\Delta S_{mix}$ 前面具有宏观粒子总数 $N$ 因子，因此具有广延性。
*   **组合学起源**：在格气模型中，$\Delta S_{mix}$ 就是将 $N_A$ 个和 $N_B$ 个不同粒子随机分配到 $N$ 个格点上带来的微观状态数的对数：$\log\left( \frac{N!}{N_A! N_B!} \right)$，利用 Stirling 公式展开恰好等于上述结果。
*   **Gibbs 佯谬**：如果混合的两种气体是**同种气体**，由于粒子具有量子全同性（不可分辨），撤去隔板不会增加任何新的微观可及状态，混合熵必须严格为零。而在早期的经典推导中若不引入全同粒子 $1/N!$ 的修正，会得出同种气体也有混合熵的矛盾，此即 Gibbs 佯谬。引入量子全同性后自然化解。

### 第 4 题：临界现象与标度律
**(a) 标度形式及物理意义**
$f_s(t, h) = |t|^{d/y_t} \Phi_\pm\left( \frac{h}{|t|^{y_h/y_t}} \right)$。
$y_t$ 和 $y_h$ 是重整化群变换下，温度和外场两个相关标度场（Relevant scaling fields）的**RG 本征值 (scaling dimensions)**。它们决定了当系统发生粗粒化和尺度缩放时，微小扰动偏离临界点的发散速度。

**(b) 导出标度律 (Scaling laws)**
*   **推导 $\alpha + 2\beta + \gamma = 2$：**
    热容 $C_V \sim \frac{\partial^2 f_s}{\partial t^2} \sim |t|^{d/y_t - 2} \implies \alpha = 2 - \frac{d}{y_t}$。
    磁化强度 $m \sim \frac{\partial f_s}{\partial h} \sim |t|^{(d-y_h)/y_t} \implies \beta = \frac{d-y_h}{y_t}$。
    磁化率 $\chi_T \sim \frac{\partial^2 f_s}{\partial h^2} \sim |t|^{(d-2y_h)/y_t} \implies -\gamma = \frac{d-2y_h}{y_t} \implies \gamma = \frac{2y_h-d}{y_t}$。
    代入检验：$\alpha + 2\beta + \gamma = \left(2-\frac{d}{y_t}\right) + \frac{2d-2y_h}{y_t} + \frac{2y_h-d}{y_t} = 2 - \frac{d}{y_t} + \frac{d}{y_t} = 2$。
*   **推导 $\gamma = \beta(\delta - 1)$：**
    在临界点 $t=0$，自由能 $f_s \sim |h|^{d/y_h}$。
    此时 $m \sim \frac{\partial f_s}{\partial h} \sim h^{d/y_h - 1}$。定义表明 $m \sim h^{1/\delta}$，故 $1/\delta = \frac{d}{y_h} - 1 \implies \delta = \frac{y_h}{d-y_h}$。
    验证：$\beta(\delta - 1) = \frac{d-y_h}{y_t} \left( \frac{y_h}{d-y_h} - 1 \right) = \frac{d-y_h}{y_t} \left( \frac{2y_h - d}{d-y_h} \right) = \frac{2y_h - d}{y_t} = \gamma$。

**(c) 导出 Fisher 标度律**
由标度假设，临界关联长度尺度 $\xi \sim |t|^{-1/y_t}$，故 $\nu = 1/y_t$。
根据涨落耗散定理（或线性响应理论），零场磁化率是关联函数在全空间的积分：
$\chi_T \sim \int d^d r G(r) \sim \int_0^\xi r^{d-1} \frac{1}{r^{d-2+\eta}} dr \sim \int_0^\xi r^{1-\eta} dr \sim \xi^{2-\eta}$。
将 $\xi \sim |t|^{-\nu}$ 代入，得到 $\chi_T \sim |t|^{-\nu(2-\eta)}$。
又由定义 $\chi_T \sim |t|^{-\gamma}$，直接对比指数即可得到 $\gamma = \nu(2-\eta)$。

**(d) Josephson 超标度关系 $d\nu = 2 - \alpha$**
被称为“超标度 (Hyperscaling)”，因为它显式地包含了空间的维度 $d$，并且联系了描述长程几何关联的指数 ($\nu$) 和描述热力学奇异性的指数 ($\alpha$)。
**失效情况**：当系统空间维数 $d$ 超过“上临界维数 (Upper critical dimension)”（对于普通 Ising 模型是 $d > 4$）时，超标度律失效。这是因为在高维下，平均场理论变得精确，重整化群中某些危险的无关参量（Dangerous irrelevant variables）开始改变宏观标度关系，使得系统不再满足简单的尺度单一缩放规则。

### 第 5 题：Bose-Einstein 凝聚
**(a) 临界温度 $T_c$**
发生 BEC 的临界条件是化学势 $\mu \to 0^-$ 且宏观凝聚尚未开始（全部在激发态）。
此时总粒子数密度 $n = \frac{N}{V} = \frac{1}{V}\int_0^\infty \frac{g(\epsilon)}{e^{\epsilon/T_c} - 1} d\epsilon$。
态密度 $g(\epsilon) = g_s \frac{V}{4\pi^2} \left(\frac{2m}{\hbar^2}\right)^{3/2} \epsilon^{1/2}$。
积分结果给出 $n = g_s \left( \frac{m T_c}{2\pi \hbar^2} \right)^{3/2} \zeta(3/2)$。
从中反解出 $T_c$ 即可得到：$T_c = \frac{2\pi\hbar^2}{m} \left( \frac{n}{g_s \zeta(3/2)} \right)^{2/3}$。

**(b) 凝聚体密度与激发态密度**
对于 $T < T_c$，化学势始终被钉扎在 $\mu = 0$。
激发态粒子密度 $n_{exc}(T)$ 由同样的积分给出，只不过温度换为 $T$：
$n_{exc}(T) = g_s \left( \frac{m T}{2\pi \hbar^2} \right)^{3/2} \zeta(3/2)$。
利用(a)中 $n$ 的表达式，可以将系数约掉，得到 $n_{exc}(T) = n \left( \frac{T}{T_c} \right)^{3/2}$。
由重子数守恒，凝聚在基态的密度 $n_0 = n - n_{exc}(T)$。
所以凝聚分数 $\frac{n_0}{n} = 1 - \left(\frac{T}{T_c}\right)^{3/2}$。

**(c) 内能 $U(T)$ 与热容 $C_V(T)$ 行为**
由于基态能量 $\epsilon=0$ 不贡献内能，对于 $T < T_c$：
$U(T) = \int_0^\infty \epsilon \frac{g(\epsilon)}{e^{\epsilon/T} - 1} d\epsilon \propto T^{5/2}$。
因此，热容 $C_V = \frac{\partial U}{\partial T} \propto T^{3/2}$。
**$T_c$ 处的连续性**：在 $T_c$ 处，内能 $U(T)$ 取值本身不发散，其对于 $T$ 的导数（即 $C_V$）在 $T \to T_c^-$ 和 $T \to T_c^+$ 的两侧极限能够平滑相接，因此 $C_V$ 在 $T_c$ 处是**连续**的。
但由于 $T>T_c$ 时化学势 $\mu(T)$ 开始随温度迅速变为负值，引入了新的热力学响应机制。这导致热容关于温度的斜率 $\frac{\partial C_V}{\partial T}$ 在 $T_c$ 处产生了一个突变的尖峰（kink）。因此 $C_V$ 虽连续，但其导数不连续，这标志着发生了一级以上的连续相变（具体而言，是三阶导数的不连续，有时按 Ehrenfest 分类算作三阶相变）。
